# 私测自主注册 · 身份链路实现

## 本轮范围

自主邮箱密码注册、密码登录、已登录旧账号首次设置密码。不邀请、不验证邮箱、不发送注册邮件；注册不验证邮箱归属，也不提供邮箱找回、账号合并或匿名给旧账号绑定密码。本轮不扩张为改密、注销或身份认证平台。

当前邮箱规范保持兼容：去首尾空白、仅域名小写，本地部分保持原样。密码不裁剪、不规范化，至少 8 个 Unicode 字符且 UTF-8 不超过 72 字节（bcrypt 的输入边界）。bcrypt cost 12；随机盐由库生成，每进程最多两个散列/校验任务，繁忙明确返回 429。按来源和账号散列桶限频，失败不记录密码、邮箱或散列。

## 数据与并发

迁移 10 新增 `account_passwords`，账号 ID 主键与外键，不改已有账号、草稿、作品及运营白名单。密码散列与新账号及七天会话在同一事务提交；邮箱唯一约束裁决并发注册。重复邮箱返回 `account_exists`，不更新旧记录。

注册响应未确认时，用户用刚才的密码登录检查；不自动重放注册并声称成功。首次设置要求当前会话，服务端从会话取得账号 ID，不接受邮箱或 owner_id。锁定账号后创建凭据，同密码重试成功，不同密码返回 `password_already_set`，不覆盖原密码。登录创建独立会话；错误不清除已有 Cookie，退出仍使用原服务端会话撤销机制。

未知邮箱、尚无密码、错误密码统一 `invalid_login`。未知邮箱也执行 bcrypt 校验以减轻明显的时序差异；不声称能消除所有侧信道或抵抗真实攻击流量。

## 接口与切换

OpenAPI 0.7.0 为契约源：

| 接口 | 用途 |
|---|---|
| GET /api/auth/methods | 当前 `email` 或 `password` 模式，不返回凭据 |
| POST /api/auth/register | 密码模式自主注册并建立会话 |
| POST /api/auth/login | 密码模式登录 |
| GET /api/me/password | 当前账号是否已设置密码 |
| POST /api/me/password | 当前账号首次设置密码 |

`AUTH_MODE=email` 为存量兼容默认值；密码注册/登录接口关闭，原邮件登录保留，已登录用户可到 `/account` 设置密码。`AUTH_MODE=password` 在服务端关闭验证码发送和验证接口，不仅是前端隐藏；前端根据实际 API 模式渲染。无效配置拒绝启动。

即使错误切回 email 模式，已有密码的账号也不能通过旧 Verify 的邮箱匹配逻辑登录。未来验证邮箱要另行设计身份与账号关联，不能删除这条保护来“恢复邮件登录”。

现有本机用户先在自己的会话设置密码，再切换本机模式，避免使存量用户失去入口；测试环境使用独立空账号验证密码模式，不把人工注入 Cookie 当作自主注册证据。ECS 与公网访问本轮不改。

## 验收边界

- 请求/响应契约及路由覆盖；重复邮箱、错误密码、未登录设置、同密码重试、不同密码禁止覆盖。
- 真实 MySQL 并发同邮箱只创建一个账号；散列不为明文，旧验证码不能接管密码账号。
- 隔离真实浏览器/API/MySQL：公开注册、设置笔名、保存草稿、退出后密码重登、文字保留；旧账号自身设置后 ID 不变；手机宽度及隐藏验证码入口。
- 已有草稿离线和冲突测试回归；主库先加密备份，再做增量迁移。
- 这些是工程行为验证，不能记为朋友已独立使用或社区已产生真实反馈。社区发现、收藏、单层评论仍需后续交付。
