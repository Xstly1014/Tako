## 既有权利与失败语义

- 本人处置列表/详情使用/my/moderation，由会话账号判权，非法/其他账号处置404。版本级与作品级明确区分；固定正式正文由详情返回，不读取工作稿。撤销一条不保证全部限制解除、不改变隐藏或展示指针。
- 原因、历次申请与结论、主动撤销原因/时间可查询，历史独立分页，分页失败保留已读记录及原游标，切处置/刷新清旧页。页内存在pending则不能再创建。列表与历史按服务端before降序，校验归属/顺序/游标和摘要。
- 理由非空、最多2000 Unicode码点；仅内存，不写本机磁盘或日志。明确确认显示处置ID/范围/固定V/理由，生成一次mutation_id和expected_revision，固定载荷重试。未知网络/5xx/429/坏成功回执保留原请求，不能改理由或另发。400/401/403/404/409明确拒绝释放原请求，但重新读取成功前不能新建；冲突/在途/冷静期分别解释。
- 成功回执只说明本次申请已确认，不能当处置现状；后续GET失败继续显示已确认并单独提供只读重试，不再POST。复核ID不是处置ID，不能把回执ID拿去读别的处置。固定详情读回、历史分页和迟到响应必须核对处置/作品/版本/账号。
- 维持后24小时由服务端时间限制再次申请，显示服务端next_appeal_at及明确时区；不以手机倒计时裁定权利。客户端可以提交由服务端校验，不用改手机时间绕过后端。保留B3.1既有运营邮箱联系入口，仅用户主动打开邮件应用，不自动发送或承诺处理时限。
- 未确认申请期间禁止静默换处置；离开需明确放弃本页确认，说明服务端可能已受理，重新进入只读、不自动补发。关闭App丢弃内存理由/操作，不承诺跨重启恢复；不扩写用户只授权C2最小标识存储的范围。退出/失效立即隐藏，迟到响应不得写回。
