# B 交互评审原型

打开 index.html。四个视图：发布预览、作者版本与权限、运营审核、匿名读者。示例内容全部虚构，不读取现有草稿或凭据，不连接 API，不写数据库，不代表 B 已实现。

可演练：授权确认、300 字软提示、正常/观察期提交语义、固定旧修订确认、待审更新/撤回、展示切换、隐藏恢复、历史权限关闭后的旧链接反馈、旧审核失效、站内文字复核。各演示仅验证局部行为，并非可连续替代真实业务状态机；刷新重置。

review.cjs 在现有 Playwright 容器检查权限提示、篇幅提示、旧审核拒绝、历史正文显示与四页面 390px 横向溢出，导出桌面/移动截图。它是原型检查，不是后端并发、持久化或安全验收。

已确认：被处置版本不在读者时间线出现，旧链接只显示通用不可访问反馈。

待评审：明确灌水阈值、复核后重复申请边界、记录正文保留、观察期提前撤销后的待审处理。页面中规则命中原因仅为示例，不作为正式规则。

重新导出（项目根目录）：

```powershell
docker compose run --rm -v "${PWD}:/materials" browser-tests node /materials/docs/prototypes/b/review.cjs
```
