# Tako 交互评审 03

独立视觉样稿。打开 `index.html`，顶部切换登录、时间线、品牌与角色。所有账号、验证码、正文、处置及管理操作都是本页合成数据，不连接邮件、账号或数据库；刷新会重置。不替代 B2 业务验收，不代表 B3 已开发。现有生产页面未修改。

## 本轮评审点

- 登录：成年角色由站姿改为靠在表单边缘的中近景。固定发型、蓝色挑染、章鱼发夹和蓝白外套；桌面与手机保持同一身份。空闲每 6.5 秒短暂眨眼，验证码聚焦时闭眼，仅响应焦点，不读取输入内容。尊重减弱动效，隐藏标签停止计时。验证码闭眼是性格表达，没有安全承诺。
- 时间线：常驻圆点、连线及“读者正在看 / 当前预览”图例。标题、正文在选中后出现，版本号及日期在详情中。切换预览不会切换公开展示，后者须单独确认。限制节点只给作者，读者完全不显示。多版本有限窗口，支持方向键、Home、End。
- 品牌：候选蓝 `#315DE8`；章鱼发夹衍生简化标识 + tako 字标。角色珊瑚色只用于形象识别，处置语义独立。尚未定稿，不回写全站 token。
- 表情包规划：问好、思考、完成、休息、轻微无语；本轮仅生成可验证的靠边姿势和闭眼帧，避免批量生成后再推翻角色。

## 已知需要继续评审

1. 两张生成帧画布相同，但不是精确的分层角色原画。短帧切换可验证节奏，正式组件应拆眼睛层并精确对齐，不能承诺完整 Live2D 效果。尚无鼠标追踪或左右转头。
2. 角色图宽 1536×1024，当前样稿保留原图。正式接入前需要确定尺寸、格式与加载预算。
3. 读者模式只评审时间线权限表达，外围仍沿用作者管理布局，不是最终阅读页。
4. 无真人 iPhone 验收；390 / 820 / 1440 为浏览器视口检查。A 的延期尾项不在这里冒充完成。
