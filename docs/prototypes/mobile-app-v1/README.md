# Tako 移动端 App 原型 V1

独立静态样稿。浏览器打开 `index.html`（建议 DevTools 切 390×844 手机视口，或直接看桌面页中的手机框）。流程：开屏 → 登录/游客 → 形态引导 → 首页 → 书架 / 消息 / 我的 / 发帖。所有账号、正文、点赞与榜单均为本页合成数据，不连接邮件、账号或数据库；刷新即重置。不替代任何业务验收，现有生产页面未修改。

## 页面与交互

1. **开屏**：深蓝品牌底 + 动态光晕，看板娘 `tako-hero-dynamic-v4.png`（伸手动态姿）浮动动画，章鱼标识 + tako 字标与 slogan 依次升起；「轻触进入」进登录页。
2. **登录页**：Q 版看板娘 + 字标；「登录 / 注册」拉起半屏面板（邮箱+密码，与现网自主注册一致），本地校验邮箱格式与密码长度；「游客访问」直接进入引导，我的页显示游客身份。
3. **引导页**：三选一（短内容 / 中篇 / 长文），单选卡片，选定后按钮可用；选择结果决定首页发现页形态，可在「我的 → 阅读偏好」重选。
4. **首页顶部**：三标签＝`长文 / 中篇 / 短内容` 三个真实形态名，不再用「发现」代标题；引导页选中的形态居中，另两个分列两侧（标签顺序随偏好动态生成）。
5. **三形态完全分离，互不混排**：短内容页＝纯错落双列瀑布块（小红书式）；中篇页＝纯知乎式全宽文字行（无图）；长文页＝社区连载频道。共享搜索栏固定在标签下方、视图之外：白底圆角输入框，三形态同一位置同一样式，切换不抖动；搜索按当前形态过滤。卡片带赞/收藏快捷动作，点开进入轻量阅读半屏。
6. **底部导航**：首页 / 书架 / ＋发帖 / 消息(角标) / 我的。发帖为半屏三选一面板（短内容/中篇/长文编辑器不在本样稿范围，点击给出演示提示）。
7. **长文页**：高信息密度、分区清晰的社区连载频道（借鉴起点的密度与分区，但布局与品牌自有）——搜索栏 → 维度条 `连载中/新开坑/已完结/社区口碑` → 主编推连载横幅（看板娘头像）→ 四磁贴入口（题材库/口碑榜/完本库/话题广场）→ 话题滚动条幅 → 双区块列表（当前维度列表 + 畅销精选带「更多›」进口碑榜）。列表行含封面、简介、字数/章数/更新时间、口碑评分与「追更」按钮；点击行进入阅读半屏。
8. **阅读半屏**：标题+作者/题材/时长元信息+正文+赞/收藏/关注作者，闭合「看到→判断→互动」链路（中篇/长文试读用途）。
9. **短内容详情页（V1.4）**：整页推入。结构＝提案标注条→作者行（头像/笔名/关注）→标题→全文→元信息（题材/时间/正式版 v1）→两级评论区→吸底互动条（评论锚点/赞/收藏/更多）。评论为业务提案（后端未实现）：两级＝楼主评论→回复，回复的回复平铺并 @被回复人；回复默认折叠 2 条可展开；自己的评论可删除（对齐现有 spec「只有删除」）；点「回复」切换输入目标并显示「回复 @xxx」；无评论时看板娘空态。更多面板含举报（C 期提案）与复制链接。短内容内容模型＝强制标题+正文（卡片=标题+正文首行，详情=全文）。

## 素材与视觉

- 角色素材复用 `frontend/public/images/`：开屏 `tako-hero-dynamic-v4.png`，登录/引导/我的 `tako-login-chibi-open-v3.png`。相对路径引用，未复制二进制。
- 品牌色 `#315DE8`、角色点缀珊瑚色 `#E98268`、正文 `#202631`，沿用 visual-system-v2 候选 token。
- 封面与文字卡均为 CSS 渐变占位，不生成新图；尊重 `prefers-reduced-motion`。

## 验证

- `node --check app.js` 通过（本机 node 位于 codex 运行时目录）。
- 未做 Playwright 截图：本机 frontend/node_modules 无 playwright，沿用浏览器人工评审；后续如需自动化，参考 brand-v3 的 review.cjs 模式补脚本与截图。

## 已知边界

1. 瀑布流为固定合成序列，无真实推荐逻辑；「混合占比」仅演示编排意图；搜索/筛选/排序为纯前端内存过滤。
2. 长文页维度与入口为静态合成数据；「本周话题」仅演示聚合入口，无话题页。
3. 登录/注册仅前端格式校验，不对接 `/api` 真实会话；游客与登录态差异仅体现在「我的」文案。
4. 手机框为桌面评审用装饰，真机全屏需另行适配安全区（底部栏已预留 env(safe-area-inset-bottom)）。
