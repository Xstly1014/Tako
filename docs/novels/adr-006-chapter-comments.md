# ADR006：稳定章讨论与既有中篇隔离

2026-11-05，N5-A。已确认[N-D03/N-D21和N5规格](n5-discussion-discovery-spec.md)。源码API0.29/迁移27；本机运行仍0.28/26，尚未接实际App/运营页面。

## 物理模型与复用边界

旧work_comments由真实外键绑定works，不能把章ID冒充work_id。新增chapter_comments带novel_id/chapter_id，书章组合外键、根和回复同章组合外键；新增chapter_comment_actions与chapter_comment_mutations。评论不存正文版本、阅读上下文或章节正文快照。

延续已有两级评论的事务、回执、分页与删除规则，复用会话、HMAC/摘要基础和既有App内存编辑器协议；SQL有真实对象差异，因此保持独立领域Store，不建立字符串多态表或提前抽通用社交框架。代价是两套评论事务需在修复共性缺陷时一起审查，不能只改中篇；本批已对旧中篇做全量真实MySQL回归。账号锁让两域发表限频共享同一每分钟5次窗口，避免切换内容类型绕过上限；旧接口和返回字段不改。

## 权限与原请求

章正文GET附加可选comment_context，HMAC域为tako-chapter-comment-context/v1，绑定Origin、书、章、正式版本；与旧中篇签名不能互换。它是提交判权上下文，不是读完证明或永久授权。没有可用服务密钥时不会伪造可发token。

新发评论先锁账号、查询原回执；原请求完全一致始终返回原结果，不因后来隐藏而改写历史。新请求锁书/章，重验当前读权、源正式版本及根/回复状态。N-D21禁止当前展示版受限后继续新发，即使来源旧版正常；普通修订后仍可用原正常版本上下文。源旧版受限拒发，但不删除已有正常评论。

回执摘要绑定书/章/完整载荷，动作摘要绑定评论ID/完整载荷；同标识换载荷409。创建/动作在同一事务保存结果，不把回执当当前状态。HTTP会话身份授权，expected_account_id仅用于检测切号，不能提供权限。

## 删除、治理与当前投影

删除/治理先读不可变章归属，再单独锁书，避免依赖JOIN优化器的隐含章/书加锁顺序。书级锁串行同书评论写入与治理：根删除和并发回复先后有确定结果；根先删则拒回复，回复先提交则随根删除。删除将根及回复正文置NULL并保留墓碑与动作/原结果，不能撤销屏蔽复活。删回复只删自己那条，根屏蔽隐藏整串，独立子屏蔽不会随根撤销自动解除。

公开查询在只读事务核对当前书/章和当前正式版，仅返回正常主评/回复、清空处置原因。本人列表含本人评论和原因，但不返回别人回复正文、书章标题或旧正文。作者按本人书管理评论，隐藏不夺走删除权；作者可删本书评论，但不能看其他评论者私密处置原因。运营可查评论并屏蔽/撤销，不能由普通作者冒充。

主评倒序/回复正序各20条；新表有章/根序列、书管理、本人序列和账号限频索引。公开和管理都不全量装载整本书讨论。数据和动作长期保留沿旧规则，本轮不新增隐含30天删除。
