# ADR 001：私密书籍与存量中篇隔离

2026-11-03，N1-A 实施决策。业务基线为 longform-business-spec.md，不改用户权利。

现有 works.source_draft_id 唯一关系表示中篇的一稿一作品。决策：新增 novels 独立实体，首段只存私密书籍资料与资料修订，不创建 Work、章或公开版本。已有 Draft、Work、Comment、Case、密文本机草稿格式均不变化。后续章稿采用显式 novel/chapter 归属，不能通过旧中篇 API 混写；N1-B 再裁决章稿存储与加密目标映射，未完成前不开放写章按钮。

N1-A 迁移 00014 只增加 novels、novel_mutations 两表，不回填／修改已有表。owner 外键、owner+created_at+id 索引、账号内原请求唯一键。书籍列表每页20，按创建时间／ID降序，资料修改不顶列表。创建请求 base_revision=0，保存要求正修订；事务锁账号行，固定载荷哈希含操作目标，记录不可变结果。重复请求返回原结果；不同载荷复用标识409；并发保存仅一个成功。GET回执用于未知结果恢复，随后读取当前资料，不能用历史回执覆盖新资料。

标题1～200 Unicode码点且非空白，简介0～300码点，六标签选1～3且不重复；不截断、不以篇幅认定质量。拒绝除换行／制表外控制字符。字节上限和章正文规则留N1-B，与当前资料接口无关。

N1-A App仅资料表单，不支持离线编辑承诺。未提交表单在内存，离开须提示；已点击提交的固定载荷持久加密以确认未知结果，账号隔离；相同请求重试，收到确定业务拒绝后可解除pending并保留输入。不改既有C1密文或其密钥，使用独立存储和密钥空间。确认结果与刷新当前资料失败分开。章节长期写作和离线恢复在N1-B接入后才开放。
