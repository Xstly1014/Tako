# M5 正式版本核对与展示决策

2026-11-03。接续M2发行、M3目录和M4复核，解决作者只能逐个打开正文、尚不能在展示决策前核对当前版与候选版的问题。完整主线：本人作品→选择候选正式版本→读取当前展示指针/候选的固定正式内容→核对差异项与两份全文→明确切换/恢复→读取管理现状→公共Reader核对结果。

## 边界与语义

- 本端独立author-works版本核对模块、展示组件、自己的AuthorWorksScreen及API可取消读取适配，测试沿已分类作者模型/服务/组件。无新后端/契约/生成声明/C1/auth/N2/依赖锁/构建；不修改工作稿，不引入第三方正文持久化，不新增作者权利。
- 基线为本次管理读取的display_version，不以last_version猜当前展示。候选来自本人正式版本列表，包括其后续页；两版本必须同作品且不同版本。作者可核对本人受限版本，但不能据此解除限制或设为公开展示。
- 标题、简介、标签集合、正文分别标记一致/有变化。正文精确比较，换行/空白变更也计入；不做摘要替换、不自造文本diff引擎，也不承诺逐字差异定位。分别展开两份完整正式正文，明确V/角色/字数；读取不完整或失败不能继续据此发起决策。
- 两份读取并行且可取消，结束后再读服务端状态；若state_revision、展示指针或最新版本与原基线不同，拒绝本次核对，要求刷新管理状态重选。换候选/刷新/退出/切号取消旧读，迟到响应不得覆盖。只在当前页面内存保留。
- 管理刷新会清除核对结果；按钮复用M1 WorkAction确认/幂等/CAS和受限优先规则，不绕过现有确认。执行时仍由服务端expected_state_revision判竞争；不得自动重选新版本或补发新操作。已有未知管理请求时禁止开启核对/新操作。
- “当前展示指针”不等于读者此刻可读，隐藏和平台限制分别标注。候选受限或作品整体受限只读核对，不提供决策按钮；正常候选可显式切换或恢复，确认区继续展示历史权限。成功后重新读现状；公共结果走现有Reader，不用作者私有内容冒充公共读取。

1. M5.1固定内容核对：版本身份、字段和全文、取消/失败/迟到及状态二次确认。
2. M5.2作者决策：可达候选入口、核对完成后明确沿M1确认/恢复/切换，受限/未知结果/竞争均有出口。
3. M5.3真实整体验证：实际发行V1/V2→切换展示指针/核对→确认候选→公共读取实际V→隐藏/受限优先与私稿不变，连同M3/M4/C1回归及精确CI。
