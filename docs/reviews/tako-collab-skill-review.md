用户要求专业化两位现有 agent 的持续协作、及时同步、避免冲突和批评性交叉审查。本端使用 skill-creator 编写仓库级 `$tako-collab`，入口在 `.agents/skills/tako-collab/SKILL.md`，按需引用协作协议与审查协议。根 AGENTS、已有 tako-handoff 只增加入口链接，不复制治理/业务规则或改同事进度。

## 实际改进

- 以双方实际远程分支、共同祖先及各自进度核对；区分已发布、未推送未知、用户认领与对方确认，不把静默当同意。
- 阶段触发同步与每次推送前检查，独占任务自主推进，跨范围只暂停重叠部分；不建立新审批流水线，不自行接管。
- 审查以原始差异与业务反例为证据，绑定 SHA，区分确定缺陷/待核实/建议，要求最小修复与复核出口，不靠互相赞同关闭问题。
- 只读 snapshot 助手可 fetch 并报告三方文件重叠候选，不合并、不推送、不输出源码/凭据；不能证明无语义冲突，也不观察对方未推送工作。
- 各端各写进度，新增本端 `parallel-progress.md`，不覆盖主开发 `primary-progress.md`。技能不隐含授权跨聊天发消息、创建代理、合并 main 或部署；也不在会话关闭后自动监控。
