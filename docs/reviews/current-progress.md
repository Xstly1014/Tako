# Tako 当前进度总览 · 2026-10-29

本文件汇总当前状态；同目录其他阶段复盘保留当时事实，不能把历史缺口直接当作当前状态。

## 背景与目标

后端开发者亲自开发和运营的 ToC 多元文字创作社区。首批通过校园论坛触达，可能以大学生为主，但不限制校园或二次元人群。Go 为后端主题，长期关注治理风控、内容消费、增长与商业化。高并发、高可用、分布式是后续需用实际负载证明的能力，当前未完成这些目标。

短内容承载日常、吐槽、分享和引流；中篇承载完整故事、情绪及经历；长文承载连载、幻想和冒险。三种入口互通。品牌为 Tako，域名 takostory.me，原创二次元看板娘是品牌形象而非内容限制。首期免费，先实现可信创作链路。

## 当前阶段

增量 A：邮箱登录 → 私密纯文本草稿 → 服务端确认 → 关闭重开恢复。尚未全部验收，不包含公开发布。

## 已交付

- 邮箱验证码、笔名、会话、退出、发送及验证限流，服务端资源归属检查。
- MySQL 持久化加密邮件队列、同请求幂等、租约、有效期与有界重试、过期任务清理。
- SMTP 与 Resend HTTPS 适配，通过 MAIL_PROVIDER 显式选择。当前 Resend 测试发件人只能向注册邮箱发送，对任意用户发信仍需域名验证。
- 草稿创建、读取、分页、保存、修订校验、幂等和冲突另存。服务端时间来自数据库。
- 快照与分层保留：24 小时每次保存，之后按上海自然日每日一份至 30 天，当前正文及独立恢复草稿不清理。维护进程独立运行。
- Nuxt/Vue/TypeScript 编辑器、Dexie 本机暂存、断网后同步、未知结果原请求重放、退出保留及原账号恢复、跨账号隔离、存储失败明确降级及导出。
- OpenAPI 契约、运行时校验、自托管 Swagger、脱敏请求关联日志、基础健康检查。
- 原创看板娘初设（精致版和 Q 版）、蓝色主视觉、年轻多元的首页与直接文案。公开社区仍明确标注开发中，无假内容和假数据。
- 本地 Docker Compose 与使用文档、阶段复盘、CI 配置；GitHub 远程已配置，未提交或推送，远程 CI 未执行。

## 遇到的问题与纠正

1. 初期接口契约遗漏：补唯一 OpenAPI、路由双向覆盖、运行时校验及响应反例测试。
2. 重复发送及宕机丢任务风险：事务性 outbox、加密待发验证码、租约及同码重试，承认外部至少一次语义。
3. QQ SMTP 未成功、域名与云邮件准备阻塞：保留 SMTP，接入 Resend 完成本人测试，未声称任意用户发信已就绪。
4. 单次发信验收后漏启动 worker：页面请求只有入队没有消费；启动持续 worker、核对最新任务 sent，补完整启动说明及 unless-stopped。
5. 邮件测试全局领取受旧任务干扰：限定各测试自建 delivery_id，防止测试发送器领取真实任务，完整竞态复查通过。
6. 多窗口旧基线、晚到响应及广播循环风险：编辑基线、待发不可变请求、序列确认、epoch 和广播抑制，测试验证不会静默覆盖新输入。
7. 浏览器存储不可用：明确内存降级，服务端仍可保存；不承诺关闭后保留内存。
8. 视觉偏离业务：移除单一文艺感，调整原创品牌形象与日常文案；不把视觉更新当作社区功能交付。

## 验收证据与限制

后端全部测试、真实 MySQL 集成、race、go vet、镜像构建通过。前端 typecheck、12 项同步测试、8 项 Chromium 回归及构建通过，桌面和手机截图已检查。

真实邮件：用户确认收件箱收到，并在页面申请、收码和登录成功。真实用户草稿编辑、关闭重开及应用重启后的完整验收尚未确认。前端故障回归采用 API 夹具，后端另有真实 MySQL 测试，两者不等于真实双设备和生产恢复验收。

## A 尚缺的收口

- 真实草稿关闭重开、应用重启以及电脑手机冲突验收。
- 真机中文输入法、后台返回、切网、配额耗尽等检查。
- 独立环境离机备份恢复，记录恢复点、耗时及正文修订核对。
- 邮件积压、保存失败、维护进程及容量的可用告警，故障注入确认通知有效。健康检查现仅数据库连通性。
- 历史恢复的授权支持流程和入口；现有底层快照不等于可交付恢复服务。
- 草稿请求去重记录及本机保留数据的长期容量治理，不能擅自清理仍有幂等承诺或未同步的数据。
- 依赖低危项与临时打包器 override、sqlc 计划差异的明确处理。
- 本地版本提交与可审查基线、远程 CI 和公网测试部署；不自动授权推送或购买资源。
