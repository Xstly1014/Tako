## 本轮行为

从原型加号的“中篇”和“我的→草稿箱”进入真实草稿箱。游客先登录，新登录先确认本机草稿许可；离线旧会话可从账号页进入本机草稿。列表合并本账号本机工作稿与分页服务器稿件，已缓存稿优先；打开服务器稿才读取全文并加密缓存，不用刷新覆盖本机脏稿或原请求。

编辑页突出标题、正文与单一保存状态。输入立即排队加密暂存，事务期间后续输入合并到下一次保存；完成事件不反写旧文字。停输 1.2 秒、前台返回以及有待同步稿时每 15 秒尝试同步；离开焦点/后台停止轮询，后台事件只尽力完成已经开始的本机保存，不声称获得系统后台执行保障。网络、暂时服务错误可重试；缺笔名、参数/环境/契约错误和本机竞争不循环提交。

服务器确认只覆盖其对应输入；新输入继续显示待同步。重连既有授权时校验 /me，不改变编辑代次或清空输入；401 仍按原授权策略隐藏锁定。原请求、冲突副本继续由已有同步核心处理，整个 Session 共用同步协调器。

存储失败保留当前输入，阻止无提示返回。导航保护在授权遮罩之外，锁定时仍生效；换错账号有切回原账号的出口，不能读取/代存旧输入。实际事务已提交但信号失败，只能以精确 seq/全文读回确认。真正本机竞争不提升未存输入的 CAS 基线，允许明确另存本机副本，原文不覆盖。

退出前从受保护回调读取本账号待同步数量，不让账号页直接依赖原生数据库。提示与账号/代次绑定，认证失效或换号立即隐藏旧数量，旧确认不能操作新账号。保留并退出继续执行原先持久锁定策略。原生工厂只在真实 App 适配中接线；M1/C2 及旧纯 Session 消费保持兼容。
