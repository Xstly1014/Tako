## 问题与结果

已确认的发布回执和之后的 GET /my/works/{id} 使用同一外层错误状态。作品状态读取发生网络错误时，即使页面已有服务器确认的 V1，仍显示“结果尚未确认，请检查原请求，勿重复新建发布”，造成相互矛盾的结果提示。该问题不会自行重复 POST，但误导用户判断是否已发布，属本端 P2 错误语义缺陷。

现状读取改为独立失败状态：保留原发布确认；现状不可用时明确提示“发布已确认，暂时无法读取作品当前状态，请重试读取”，只提供 GET 重试。没有新鲜状态时继续不展示公开阅读入口，不猜测作品是否隐藏、受限或审核通过。读回成功移除该错误并展示真实现状。

没有修改 PublicationFlow/journal 的恢复、原请求、发布未知或保护语义；真正 POST/原预览恢复的失败仍沿既有流程处理。账号变化依旧由当前会话/代次和组件卸载保护，401 不会因本地 read catch 向另一账号显示旧结果。
