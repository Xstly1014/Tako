## 业务问题与修复

从作品管理发布后“进入作品管理”原先replace当前页，栈中原作品管理仍保留；列表的“返回我的”再back会先退到重复管理页，需要第二次点击。发布参数无效时“返回作品管理”也会制造同类重复。没有正文丢失证据，但按钮的实际目标与业务文案不符。

本端仅调整三个明确目标：发布结果→作品管理、无效发布入口→作品管理、管理列表→账号。使用既有Expo Router dismissTo，找到目标时收起其上页面，找不到时替换当前页；普通发布“返回”仍保留原来的上下文返回和未确认操作拦截。没有清除会话、稿件、发布标识或重发动作。

已查Expo58/Router58本地依赖及[对应官方接口](https://docs.expo.dev/versions/v58.0.0/sdk/router/#imperativerouter)，不新增依赖或修改共享构建。源码归本端M1/C2，不接管C1/auth、同事搜索、锁或汇总文件。
