# 中篇举报治理 · 阶段交付

2026-11-16，Asia/Shanghai。基线：已合并主开发 `4322dac`；Agent 暂停检查点提交 `50edece`。用户明确将本业务前后端、限定契约和迁移交给并行端，主开发继续短帖与设备。

## 用户目标与最终链路

本轮按一条完整业务交付：App 阅读正式内容 → 举报固定正式版 → 断线或重复提交读回原记录 → 我的举报查询 → Web 核查原版正文和说明 → 无需处置/版本限制/作品限制/关联已有处置 → 保存回执 → App 从列表和详情读取 → 复查当前公开入口。

同账号同版本终身只保留一条举报，属于用户本轮明确决定；新版是独立对象。重复请求不覆盖原说明。举报本身不限制内容，运营使用已有治理权限。举报人不读取其他举报人的记录，作者没有举报人身份接口。

## 实现与契约

- API 0.38.0；迁移 **37** 新增 `content_reports`，唯一键 `(reporter_id,work_id,version)`，队列和本人记录索引。仅独立测试库执行了迁移，没有升级常驻 3300。
- 六条新 HTTP 路由：正式版举报提交、本人列表/详情、运营列表/详情/结案。OpenAPI 是源，生成 App 声明并通过契约一致性检查；运行时验证与路由/响应测试使用同一契约。
- 创建事务锁定会话账号，查询原记录优先于当前可见性；新举报在事务内验证版本可读，因此原内容后来不可读仍可回查自己的回执，另一账号不能借此新建记录或读取原文。
- 结案事务锁定报告行，检查原修订；相同结案请求可重放，冲突回执不可覆盖。关联生效处置必须属于同一作品，且整件作品或目标版本适用。operator_id 仅保留在内部审计字段，回执不输出举报人或运营人账号。
- 原治理 `ModerationResult.id` 是审核任务编号。本轮补充可选 `case_id`，不改旧 id 语义；实际创建的 case_id 与幂等结果一起保存。不能靠空库里任务/处置编号碰巧相同建立关联。
- Web 将限制与举报结案分两步，按账号保留原操作标识、原修订和各阶段结果。响应未确认时只重试原操作；限制已存在时可明确关联原生效处置继续结案，禁止关联其他作品或已撤销处置。
- 给作者的处置原因与给举报人的回执分别填写、分别使用，不把回复举报人的文字自动复制给作者。

## App 与 Web 使用结果

App 阅读页举报当前实际版本，账号页可进入我的举报；列表分页、刷新当前选中回执、失败保留说明、离开未提交内容确认、切号后清除旧页面均已接入。重复提交返回较早原记录时列表按编号排序，后续翻页合并去重。服务端以会话账号判权，不接受客户端 owner_id。未确认结果可从本人列表回查，关闭 App 后不自动补发。

Web `/ops/content-reports` 提供待核查/已结案/全部筛选、分页、受保护原文、处理与回执，以及公开访问复查。结案后从待办列表移除相应条目。已有待确认操作可恢复，不更换原操作编号来隐藏错误。

## 验收证据分层

| 层级 | 实际证据 |
| --- | --- |
| 静态 | App 类型与 lint、Web 类型通过；生成声明与 OpenAPI AST 一致 |
| 客户端模型 | 三项测试验证同版重试、原说明保留、游标/顺序/重复记录拒绝及结案状态完整性；新增客户端 body 为对象，由原请求适配器统一编码。已纳入现有 model 分类，整组 206 项通过，无跳过 |
| 真实 HTTP/MySQL | 独立 `tako_reports_*` 数据库迁移 1–37；举报整链、跨账号 404、非运营 403、未知字段拒绝、隐藏后本人回查、另一账号不可新报、无效处置关联拒绝、结案重放/冲突及无需处置分支通过；路由覆盖与相关治理回归、Go vet 通过 |
| 真实 Web | 从原报告核查固定原文，执行版本限制并结案；再执行整件作品限制与已有生效处置关联。治理后公开页面显示不可访问 |
| App 源客户端→实际 HTTP | 原生专用测试会话，使用 App `ReportsAPI` 和原 `request`：举报 **16** 提交、重复回查同编号且不覆盖原说明；Web 对该举报结案后，同一原生会话通过列表和详情读回 `resolved/handled` |
| 隐私分离 | 报告 **6** 的作者处置原因和举报人回执分别填写，页面只将给举报人的回执作为举报结果；报告 **12** 通过关联已生效处置完成旧未确认链路，不重复限制 |
| 真机 | 本轮未构建、安装或操作 Android 真机。该部分按分工交主开发，不能以 HTTP 联调冒充设备验收 |

所有业务数据均为本地合成验收数据，不是用户举报量或治理成效。浏览器环境通过测试二进制的条件夹具启动，角色引导端点不编入生产 API；验收服务仅绑定本机，阶段完成后停止。普通集成测试定向清理自身资源，浏览器夹具库保留作诊断。
