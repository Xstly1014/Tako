# App 作者关注与粉丝名单

2026-11-19，开发基线 `9f1a9e8`。用户决定作者可以打开自己的粉丝名单，周边交易暂缓。

## 可用路径

- 读者在中篇正文、短帖图文详情或长文章节目录关注作者。提交前提示作者能看到自己的昵称。关注关系由当前公开作品解析到稳定作者账号，同名和改昵称均不改变归属。
- 「我的 → 关注」列出本人关注的作者，「我的 → 粉丝」显示粉丝总数、当前昵称与关注日期。名单仅对会话本人开放。V1 浏览器原型的「我的」也补上粉丝入口，使用演示数据。
- 社区搜索栏右侧进入关注动态。每个作品一行，按当前展示版或长文可读章节的正式版时间排序，点开回到原阅读入口。首次关注会看到该作者已有的公开作品。隐藏、整件或展示版受限的内容在再次读取时移出动态。短帖沿用测试环境及 App 构建开关。
- 读者可以从内容页或本人名单取消关注，包括作者已经撤下最后一件公开作品的情况。若网络中断或旧页面提交，App 重新读取关系供本人核对。

## 契约与数据

API 0.40，迁移 39 新建 `author_follows`。同一读者与作者的关系唯一。写操作按登录读者加锁并比较修订号。作品标识用于核对作者，关系标识可在本人名单中用于取消。禁止关注自己。关注与粉丝分页仅提供昵称、关系标识、修订号和关注时间；表中不复制邮箱和正文。作品动态遵循当前可读状态，书架追更仍按书独立管理。列表每页 20 条。
