# App 固定预览与正式发布阶段复盘 · 2026-11-02

## 交付与规格核对

本端按用户“继续”推进 C2，同事继续 C1 草稿存储/同步/编辑。新增“我的 → 作品 → 发布服务器已保存稿件”，只读取本人服务器稿件，不构成第二套草稿编辑器。C1 后续用草稿 ID/已确认修订导航交接。

沿 B1/B2 和 OpenAPI 接入授权确认、标签/简介、页内补笔名、固定修订完整预览、显式正式发布、幂等确认、过期/冲突处理及发布后本人现状读取。隐藏中发布仍隐藏，回执不等于现在公开或审核通过；未改 API、schema、生成类型或既有业务权利。

用户明确选择 SecureStore 保留最小发布标识，每账号一个记录，限 1 KiB；只有格式版本、账号/草稿/预览 ID、修订、mutation_id、expected_version，不含标题、正文、简介、标签、密码、令牌。写入成功才发 POST，失败不发送；重入只 GET，未确认结果需要再次主动检查。401/403 保留标识，原账号在线重登后核对；确认结果至主动收讫才清除。损坏/账号不符保留且拒绝覆盖。同账号多页面用写互斥与标识比较保护，旧页面不能清理新请求。

准备预览的未知请求只在页面内存冻结，关闭后需重新准备，不增加正文存储。结果未知时本机过期判断不阻止原请求确认；服务端明确过期才结束原记录。详情见 [C2 规格](../mobile-publication-spec.md)。

- 本机类型、Expo lint、38 项纯模型、9 项服务组、3 项门禁通过；OpenAPI 重新生成比较通过。评论/历史阅读/作者管理/发布四套断网组件通过，零 skip/todo。
- 新模型覆盖原请求冻结、授权、存储失败不发 POST、记录不含正文、重建实例只读恢复、过期与未知结果、多个页面互斥、错误记录、切号/迟到响应、明确冲突和会话失效保留。
- 真实 MySQL/API 覆盖本人稿件/跨账号拒绝、固定 R1 预览后保存 R2 而发布仍为 R1、已提交后丢响应、新实例 GET 确认、不重复发布、同预览换标识仍返回原版本、隐藏中追加 V2、并发预览版本冲突、工作稿不被覆盖。只创建合成账号/稿件，结束隐藏测试作品并注销，不发真实邮件。
- 实际组件从 M1 入口操作，覆盖默认未授权、页内笔名不丢表单、旧修订不自动换新、准备不发表、存储失败不发送、丢响应、卸载/重挂组件只读确认、读取隐藏现状与切号清理。DOM 控件/内存 SecureStore 适配器不证明手机键盘、返回、真实存储或系统终止可靠性。
- API 未改，本机未重复全量后端 race/契约集成；既有远程 Backend 工作流负责。远程执行结果推送后补记。未构建 APK、未安装手机、未做恢复演练，不沿用旧包证据。

## 文件范围与退出条件

新增 `mobile/src/api/publications.ts`、`mobile/src/publication/**`、`mobile/src/app/publish.tsx`、发布模型/服务测试、`scripts/mobile-publication-ui/**`；M1 页面仅增加发布入口，CI 本端工具增加分类。未修改同事 C1、会话、依赖、后端或共享入口账本。

- P1，阶段合并前：远程 Mobile/Backend CI 通过；推送前拉取 main、核对同事进度、重验共享改动。只推本端分支，不推 main、不强推。

- P1，下一安装包前：整合 C1/M1/C2、冻结源码、构建并核对 bundle，源码检查不等于新包可安装。
- P0，真实移动作者交付前：真机验证 SecureStore 失败/重开、失效与同账号恢复、返回/键盘/终止；损坏或不可解密标识须核对原结果后明确处置，不能清空来绕过未知状态。卸载/清除系统数据不能保证保留标识，不承诺零丢失。
- 前端 moderate 审计仍由主开发处理；不连接 ECS、不公开部署。
