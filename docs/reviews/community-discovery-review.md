# 社区发现第一条链路复盘

本批目标：让正式作品进入真实浏览入口，让运营能编排精选，让官网、读者与创作区之间可以往返。依据 [已确认规格](../community-discovery-spec.md) 与 [技术设计](../community-discovery-design.md)。收藏和单层评论尚未实现，不将本批算作完整反馈闭环。

## 做了什么，为什么这样做

- 官网保留原有品牌视觉，主入口改为进入真实 `/community`，写作入口仍可达。
- 社区取真实公开中篇，提供最新发布、风格标签与人工精选。卡片使用当前展示正式版的标题、作者简介、标签和笔名；没有截取正文、捏造热度或用未交付短内容/长篇入口填版。
- 最新按首次正式发布而非修订排序，每页 12 条，以时间与 UUID 稳定分页。同一响应的分区、标签计数使用一致读取快照。
- 精选由运营在 `/ops/curation` 编排最多六个位置，支持检查候选、明确确认替换/移动、清空、处理冲突及检查未确认请求。普通用户不能因看到前端链接取得运营权限。
- 选入记录绑定作品的公开资格代次。隐藏、作品限制或当前展示版限制，在原业务事务中递增代次；恢复公开不恢复旧精选资格。历史非展示版本受限不连带撤出正常当前版。
- 共享 `AppHeader` 接入官网、社区、写作、作品管理、发布、阅读、账号设置和治理页面；共同导航锚点固定，阅读正文仍保持窄版。手机采用展开菜单。
- 稀少内容状态也重新编排：单个精选使用宽位、少量最新作品采用紧凑行式卡片，不让一张窄卡片旁边空出两列，也不填假作品。

## 主要约束与策略

| 问题 | 策略 | 验证 |
|---|---|---|
| 仅查询过滤会让恢复作品自动回精选 | 单独的资格代次，不随恢复或撤销回退 | 真实 MySQL 与浏览器确认隐藏/恢复、当前版限制/撤销后均须重新选入 |
| 原选入请求丢响应，恢复后重放可能重新选入 | 先读取不可变请求确认，再做当下状态校验；重放不重新执行 | 服务器提交后故意丢响应，重试只一条确认；隐藏恢复后重试也不复活精选 |
| 两个运营旧页面互相覆盖，或候选刚经历隐藏恢复 | 全组编排修订与候选作品状态号共同检查 | 并发只一条成功；过时候选明确冲突 |
| 编排更新与审计写失败造成部分成功 | 位置、全组修订及输入审计同事务 | 注入确认写入失败，全组状态与原来一致；隐藏事件失败也不误撤精选 |
| 新入口泄露已隐藏标题或未公开正文 | 列表与读者共用公开条件，卡片不查询正文；读者入口再次判权 | HTTP 契约反例、匿名 SSR、隐藏后卡片消失；服务端不返回受保护元数据 |
| 多页导航宽度变化、手机挤成一行 | 公共头部移出各自主体宽度，手机折叠 | 跨页面品牌坐标一致；三档布局及原分区几何断言通过 |

## 证据与交付边界

- `python scripts/test_backend.py`：schema 11 全后端真实 MySQL、请求/响应契约、路由覆盖、race 及 vet 通过。
- `python scripts/test_b1_live.py --community --b3 --b2 --password --restore`：独立 writing_test 的真实 API、web、数据库与浏览器，包含社区、精选丢响应重试、隐藏恢复、匿名 SSR、标签加载失败重试、共享导航坐标、手机菜单；同时回归 B1/B2/B3.1 与密码注册。没有向真实邮箱发信。
- 合成服务的 24 表加密恢复在独立 MySQL 容器验证，全字段指纹一致，34.38 秒；不是 ECS/OSS 新数据离机恢复或生产 SLA。
- 前端 typecheck、生产镜像构建通过；原草稿 9 项浏览器回归通过。
- 布局协议夹具在 390/820/1440 验证长标题、24 版本、空态、错误、设置/记录/内容切换几何稳定；这部分不是 API 业务证据。
- 社区桌面、手机与编排截图只使用合成内容，已目视检查；不代表社区已有作品供给或运营效果。

浏览器测试曾在跳转尚未完成时用同名标题定位读者页，因精选与最新列表均有标题而触发严格定位失败。修正为按目标作品链接及读者一级标题等待，未放宽业务断言。用作品 ID 而非共享测试标题判断隐藏，避免把另一篇同名作品误判为泄露。

## 本机更新

升级前已加密备份，再迁移到 schema 11、OpenAPI 0.8.0，更新本机 API/web。账号、作品及密码模式保留，没有部署 ECS、开放公网或推送远程。

本次再次验证了部署后的入口检查：API 先就绪时 web 仍可能短暂 504，不能凭 API 就绪宣布整个站点就绪。分别等待实际入口后，官网、社区、写作、作品管理、账号与编排页面均 200；匿名编排 API 401。没有把单实例重建称为零停机部署。

## 三栏账本与下一步

| 层次 | 当前状态 |
|---|---|
| 代码能力 | 真实发现、人工精选、资格撤出与共享导航已实现，本机可用 |
| 已验证行为 | 自动化真实服务及布局回归通过；用户本人已确认官网进入、找到作品、阅读返回正常；精选选入及隐藏恢复不回榜符合预期 |
| 真实用户结果 | 尚无新增外部发现、反馈或回访样本 |

后续优先接收藏与单层评论，遵守已确认的作品归属、版本标记、评论删除与独立处置规则；需要补充明确评论输入及实际阅读版本的写入边界。B3.2 仍暂缓，A 真机尾测仍搁置。完整反馈闭环还需互动实现与非开发者实际任务验证。

## 用户本人确认

用户已确认官网进入社区、找到作品、打开阅读并返回社区正常；运营选入测试作品后，隐藏再恢复不会自动回精选，符合预期。此确认覆盖本机发现与编排功能，不推定为视觉最终定稿、外部读者读完或反馈留存结果。
