## 配图暂存接口验收

2026-11-10。API 0.31 和迁移 28 增加仅 test 环境可用的私密暂存接口。浏览器调用仍验证来源，原生调用仍走独立会话。服务端先认证，再读取并解码。规范化后的图片和元数据存同一 MySQL 事务，初始限制为每账号 16 张暂存图、每 API 进程同时接收和处理两个上传，单张输入与重编码产物分别限制在 8 MiB。相同作者、上传 UUID 和文件重试返回同一元数据。字节不同返回冲突。图片 ID 只在作者账号作用域内解析。

隔离 MySQL 库迁移成功。真实 Gin 路由与 MySQL 验证了 JPEG/PNG、拒绝伪造类型、损坏文件、超出字节和像素上限、来源验证、重复上传、跨账号拒绝、配额并发，以及去除原文件附加字节。请求和响应契约、路由覆盖、定向 Go race、vet 和 App 声明生成检查通过。首次验收发现专用错误码尚未加入错误枚举，补齐后重跑通过。

下一批将把图片 ID 与固定快照绑定，并处理引用、作者移除和回收的竞争。开放前补发布/审核前后及旧 URL 判权、原生相册与弱网、库恢复与容量验收。当前阶段只验证了私密素材，既有 3300 入口仍运行上批镜像。未在设备上安装本批。

## 固定预览验收

2026-11-10。API 0.32 和迁移 29 在 test 环境加入本人创建及读取预览。预览 24 小时有效，每账号最多 32 份有效预览。同一预览 ID 和归一内容重试返回原快照，改变正文或图序需要新 ID。跨账号读取统一返回 404。图片按作者、素材和顺序固定，数据库外键阻止删除仍被预览引用的图片。关联只保存长文 ID，准备时复用现有公开判权；作者能够回看原预览，确认提交时还须重验关联资格。

真实 MySQL 与实际 HTTP 路由验证零图、四图与非法图片数量、重复图、跨账号图、失败事务无残留、原请求恢复及过期、其他作者及未发布或隐藏长文的拒绝、引用图片不可删除。后端定向 race、契约覆盖、vet 和生成声明检查通过。迁移只用于独立集成库。尚待验收的是提交事务与先审后发、运营纠错、公开图片和关联卡片权限，以及预览引用释放与回收竞争。

## 首发分流与公开图文

2026-11-10。API 0.33、迁移 30 在 test 环境加入固定预览确认、原回执查询、公开 V1 详情及读图。作者必须确认授权。服务在持有同一作者事务锁时重验预览有效期、关联长文和账号观察期。正常账号首发，观察期账号进入先审。预览一次性消费，丢响应可按原请求取回固定回执。先审保留为待处理记录，观察期到期也不改变提交状态。

真实 HTTP 路由与 MySQL 覆盖游客未授权提交、跨账号预览与回执隔离、未确认授权、重复消费、变更原请求载荷、过期预览、关联在提交前隐藏、首发后卡片隐藏和恢复、V1 正文及图片顺序、错图 ID 与先审正文和图片拒绝。定向 Go race、契约覆盖、长文阅读/发布/账号观察期回归、vet 和生成 App 契约检查通过。迁移在独立集成库执行。

运营待审工作台、人工决定及处置撤销仍是开放前条件。作者隐藏、修订和历史权限必须与媒体判权一起交付。首发当前引用固定预览，后续回收只释放未被提交或正式版本引用的素材。短内容频道、App 与设备验收另行追踪。

真实 HTTP 路由与隔离 MySQL 验证了普通账号不能读运营队列和待审图片、先审通过后发布、驳回原因仅授权方可读、过期状态动作被拒绝、作者隐藏与平台限制叠加、撤销后仍尊重作者隐藏、恢复不改变首发时间，以及 12＋1 分页的锚点隐藏后仍可继续读取。原先审回执在通过后仍保留原结果。契约路由、请求/响应、定向 race、vet 和 App 生成声明检查通过。迁移仅应用于独立集成库。

作者修订及历史版规则、复核、素材回收、实际 App 与 Web 运营页面仍是开放条件。设备和运行证据按已有门槛另验。

## 正式版本、作者修订与历史权限

2026-11-10。API 0.35、迁移 32。迁移将已有首发快照登记为正式 V1，旧 V1 图片路径继续可用。正式版与先审修订分开保存。普通作者提交正式帖修订产生新版本，观察期或已有待审时进入先审。替换待审稿只保留最新队列项，不消耗正式版本号。运营可查已提交修订及其图片并通过或驳回，原受理回执保留。首次发布时间继续决定频道排序，频道卡片返回当前展示版号和首图。

作者可切换正式展示版，恢复公开时采用最新正式版。历史正文默认关闭，读者可见版本节点；正文和图片按同一个版本条件读取。隐藏或全帖平台限制优先。真实 HTTP/MySQL 覆盖旧图 URL、历史开关、跨账号私有版本拒绝、待审替换、过期观察期、仅最新可过审、通过分配下一正式版、驳回保留原因和原展示版。首轮回归的合成夹具删除顺序漏掉新增外键，修正后仅清理对应隔离库夹具并重跑通过。定向 race、路由覆盖、请求响应契约、vet 和生成声明通过。

本批修订入口适用于已有正式版的帖子。首次待审替换、普通修订后审及版本级处置、站内复核与素材回收为开放前工作。当前全帖限制统一关闭所有公开版本。迁移仅在隔离库执行；存量库带数据升级及 Android/App 仍需另外验收。

## 修订后审与单版本处置

2026-11-10。API 0.36、迁移 33。运营修订队列区分先审与后审，存量普通修订经迁移进入后审。后审通过保留原发布版本与展示选择。运营可限制或撤销指定版本，审计保留目标版和原因。全帖限制与单版本限制分别生效。当前展示版受限时，频道和主详情不可读，历史已开放时其他可读版仍可直接访问。受限版从公开时间线移除，正文和图片拒绝读取。作者可看受限版本及原因，恢复公开时选择最新可展示版。撤销版本限制保留作者当前展示选择。

真实 HTTP 与 MySQL 验证了普通修订排队及通过、限制关闭待后审、同一素材在不同版本分别判权、受限版本选择被拒绝、作者隐藏与恢复、撤销后保留展示版。首轮发现既有审计列长度不足以保存撤销动作，已扩展该列，在独立集成库完成 33→32→33 后重跑通过。契约路由与请求响应、定向 race、vet、App 生成声明检查通过。
