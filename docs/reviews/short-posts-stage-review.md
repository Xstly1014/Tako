## 配图暂存接口验收

2026-11-10。API 0.31 和迁移 28 增加仅 test 环境可用的私密暂存接口。浏览器调用仍验证来源，原生调用仍走独立会话。服务端先认证，再读取并解码。规范化后的图片和元数据存同一 MySQL 事务，初始限制为每账号 16 张暂存图、每 API 进程同时接收和处理两个上传，单张输入与重编码产物分别限制在 8 MiB。相同作者、上传 UUID 和文件重试返回同一元数据。字节不同返回冲突。图片 ID 只在作者账号作用域内解析。

隔离 MySQL 库迁移成功。真实 Gin 路由与 MySQL 验证了 JPEG/PNG、拒绝伪造类型、损坏文件、超出字节和像素上限、来源验证、重复上传、跨账号拒绝、配额并发，以及去除原文件附加字节。请求和响应契约、路由覆盖、定向 Go race、vet 和 App 声明生成检查通过。首次验收发现专用错误码尚未加入错误枚举，补齐后重跑通过。

下一批将把图片 ID 与固定快照绑定，并处理引用、作者移除和回收的竞争。开放前补发布/审核前后及旧 URL 判权、原生相册与弱网、库恢复与容量验收。当前阶段只验证了私密素材，既有 3300 入口仍运行上批镜像。未在设备上安装本批。
