# 处置后读者结果核验整包

2026-11-11，Asia/Shanghai。基线 `135047f`，主线 `4d8602b`。本轮补齐从运营原记录到匿名读者观察的链路，避免把“通过/撤销”直接展示为读者已经能够访问。

## 业务链路与口径

从已有班次待办、跨班次对账或复核报表的明细发起核验 → 根据已保存的原任务定位重新读取运营记录 → 匿名核对当前展示版和原目标版本 → 保留快照 → 重开或返回来源。三个入口共享同一实现。

| 情况 | 最终行为 |
| --- | --- |
| 原任务仍 pending | 显示尚待决定，不发匿名内容读取，不宣称处置已生效 |
| 先审稿被驳回、撤回、替换 | 显示本稿未发行，不把 candidate_version 当成正式发行版 |
| 有决定/已发行 | 匿名读取当前作品与原记录版本，分别给出可读状态和实际版本 |
| 目标版不是展示版 | 分别呈现两者，不把版本不同当作审核异常 |
| 匿名返回 404 | 仅说明该匿名入口未公开可读，不猜作者隐藏、其他限制或历史开关原因 |
| 网络/环境/契约/权限错误 | 保留未完整，不能转换成不可读或成功恢复 |
| 期间结果变化 | 记录为 changed，清空可被误当稳定结论的可读结果，允许重新核验 |

作者复核保留原申请的决定与当前处置 state/revision。例如申请曾维持，但原限制后来撤销，两者分别呈现。当前展示版和目标版都不能公开读取时，也不宣称撤销失败；本包没有足够证据归因。

核验前后重新读取原运营记录，匿名结果观察两轮；只有两轮投影相同、原记录投影未变化才给完整观察。它不是跨接口数据库事务，不承诺排除所有瞬时变化，不提供自动处理率或自动处置。

## 范围、实现与安全

仅触及 `agents/author-support/**` 与本端文档。产品 OpenAPI、共享迁移、主开发 Web/App 不变；匿名读取复用已有 `work/readVersion`，保持 `credentials: omit` 和测试环境响应校验。运营读取使用既有测试运营会话和原 GET，所有操作均不写审核结果。

本地命令桥版本 1.2.0，新增 `POST /local/effect`，参数为 `{kind,id,queue,itemId}`；kind 只允许 shifts/reconciliations/outcomes。作品、版本、caseId 由服务端从原报告解析，客户端传入额外 workId 或自选路径一律拒绝。返回 202 作业状态，结果通过现有 `state/report` 读取。

错误语义：非法命令 400；源记录或任务不存在 404；旧任务缺定位 409；已有作业运行 409。核验中的业务读取失败作为 incomplete 报告保存，带固定错误码与可用的 HTTP 状态。单次请求有既有超时，停止信号传递至运营与匿名读取，预取消不发请求。

本地 SQLite 新增追加式 `reader_effect_reports`，history/report 的 kind 增加 effects。每次重查生成新观察，保留旧证据；报告仅存任务、作品、版本、决定、可读投影及时间，不存标题、正文、处置原因、作者说明或凭据。

## 验收证据

- 类型与浏览器脚本语法通过。15 项相关测试：7 项新核验语义/元数据验证，以及 8 项命令桥与工作台回归（包含新增端到端核验命令）。
- 覆盖审批通过但目标不可读、另一个展示版可读、原记录与匿名结果变化、网络/权限错误、预取消、原申请决定与当前限制状态不同、先审未发行稿、源任务绑定及禁止客户端作品定位。
- 真实本地测试 HTTP/MySQL 与浏览器：从报表 5 的复核 **23** 发起核验，保存报告 **1**。原记录 revoked，版本 V1，当前处置 revoked/revision 2；当前展示入口与目标版入口均匿名不可读。页面未宣称“恢复成功”或替它归因。
- 从班次 2 的后审任务 **70** 发起核验，报告 **2** 为 awaiting_decision，未发匿名内容请求。
- 服务重启后，浏览器读回核验 1 的原记录与两个匿名不可读结果；“返回来源”打开原报表 5，重开链路通过。
- 上述是本地合成业务数据。读者可读、另版展示及并发变化的其他组合使用受控 transport，不冒称线上或真实变更验收。

## 退出条件与后续边界

本包退出要求三个入口可发起、原记录与匿名结果分开呈现、失败/变化不误判、报告可重开、可重新核验并返回来源。

P1：若需要解释不可读原因，需由产品授权并由主开发提供运营可读的最小状态接口；当前禁止借作者会话跨账号读私有状态，也不靠猜测填原因。接口和权利明确后再扩展。

P2：多人线上使用仍需统一登录与真实运营身份，沿工作台原边界另行集成；本轮本地标签不成为业务权限或正式审核凭据。
