# S1 · 公开中篇搜索 API 交付

2026-11-02，主开发。业务起点/用户裁决见 business-inventory-after-c1.md 与 mobile-search-spec.md。此前基线 main1793f7f，peer a2905e8；本轮新增业务为读者主动找作品/作者，交付限服务端，不称App入口已开放。

## 实现与既有权利

新增 GET /api/search，搜索当前可公开展示版标题/简介与作者当前笔名，不读正文/私稿/预览/历史版本/评论。复用 discoveryFrom、discoveryVisible、WorkCard 和统一错误/日志/no-store；不新建作品模型或派生索引。按首次正式发布时间/ID倒序，12条一页，关键词散列绑定游标。换词、坏游标、缺词、超长、控制字符、重复/未知参数、坏URL编码为400；无命中200空数组；关闭发布或数据库故障503，不回查询词/SQL信息。

字面匹配使用参数化LIKE及显式ESCAPE，%/_/!和反斜线是普通文字；SQL LOWER与Go规范化实现英文大小写不敏感。2秒上下文预算继承取消，不声称包含匹配可走普通前缀索引。OpenAPI为事实源，Mobile声明由固定openapi-typescript生成，再按原格式格式化；未手改类型或锁。无数据库迁移、无新依赖。
