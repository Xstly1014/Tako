# 作者反馈工作台交付复盘

2026-11-03，并行端。依据用户明确选择的[完整规格](../mobile-author-feedback-stage-spec.md)。新交付是本人作品管理直达反馈、上下文校验/返回与内存保护；回复、删除、分页和原请求协调复用原CommentsPanel，不将既有评论能力重复计算为新权限。

## 业务实现

本人作品→处理作品反馈→私有接口验证归属→公共作品读取互动上下文→原线程/回复/作者删除→确认并读取结果→返回管理。坏ID拒绝，公开作品不代表有作者工作台归属。隐藏/整体受限或公共展示版不可读不显示评论，不自动恢复公开。返回投影只有ID/标题/互动上下文，不保留正文或给评论加版本标签。

收起面板保留当前内存输入及原操作；有输入或待确认删除不能清空重读。路由离开须明确丢弃。核对原评论规格后修正了最初按generation重建编辑器的实现：同账号失效隐藏私有视图、锁定编辑器，同账号重登读取资格后仍按原组件明确恢复；读取失败只重试GET且不销毁旧编辑器。换账号才清空旧上下文，关闭App不恢复。不修改共享评论组件、认证或C1存储。

## 失败与修正

首轮用V2标题寻找已切回V1的目录项，改按实际展示标题。另一次故障注入过早中断了父管理详情读取，改为等待父入口可操作后才开始注入；StrictMode两次读取不能靠只中断第一次来保证错误态，改为明确保持故障直到页面错误后再由测试恢复。返回断言最初忽略同账号重登也会按既有管理隔离清除旧选择，现分别验证正常返回保持条件与会话变化后不恢复旧选择，不为测试更改原规则。lint指出effect同步setState，状态清理移至显式重读事件，未放宽检查。
