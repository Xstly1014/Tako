# 前端阶段复盘 · 2026-10-29

## 交付范围

Nuxt 首页、邮箱登录、笔名、草稿列表、纯文本编辑、本机暂存和同步、冲突另存、退出保留与原账号恢复。没有公开作品、看板娘素材、私信、支付或发布系统。

## 本轮纠偏

1. 最新依赖的 rolldown 包返回 404；先核对兼容性，随后升级至修复版 Nuxt 与 Vue，保留有记录的临时打包器 override。不以安装成功代替审计。
2. 发现跨标签页的登录广播可形成循环，改为显式登录才广播；会话刷新不再次广播，旧响应由 epoch 检查丢弃。
3. 发现另一窗口刷新缓存后旧编辑页可能继承新修订号，新增编辑基线与本机分叉保护及回归测试。
4. 浏览器存储失败不能直接让服务端保存停摆，增加明确的页面内存降级；仍告知关闭页面会损失未同步部分。
5. 浏览器测试最初使用不安全 HTTP 容器主机名导致随机数 API 不可用，改为 localhost，并为真实页面增加明确的安全上下文提示，没有伪造随机数 API。
6. 退出仅保留草稿，不保留登录表单中的邮箱预填数据；其他账号界面不显示旧账号草稿。
