## 问题与决策

新增仓库技能 `tako-restart` / `tako-handoff`，前者只恢复本机 3300，后者核对业务现状、证据和并行边界。流程不互相重复；重启文档作为交接的共用运行手册。新技能具备选择器元数据，重新加载项目后使用，标准显式调用为 `$tako-restart` / `$tako-handoff`。

新增 `scripts/local_restart.py`：缺少 API/Web 镜像时构建，按需补 Go 缓存卷，验证原数据库 namespace 后执行向前迁移并启动服务；不会重造数据。配置、身份 SQL 或数据库卷缺失直接拒绝，意外丢卷转入明确恢复决策。安全错误码替代可能泄密的 Docker 原始输出。`--rebuild` 用于已有镜像需要跟进源码。
