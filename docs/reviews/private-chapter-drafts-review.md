# N1-B：私密章节写作与独立恢复

2026-11-03。规格：[长文业务](../novels/longform-business-spec.md)、[ADR002](../novels/adr-002-chapter-drafts.md)。源码基础55911c1，随后普通合入同事M2至4565dda；最终提交另含章节历史清理回归。当前没有APK、真机或真实创作者结果声明。

## 解决的业务问题与交付

作者开书后需要真正写章，断网或两端编辑也不能丢内容。本批交付“私密书籍→章节草稿→加密本机暂存→联网同步→冲突另存新章节→继续编辑”的完整私密链路。底部创作面板和我的长文均可进入；已缓存书籍可从草稿箱离线续写。章节不进社区，不占正式序号，不开放发布、完结和追更。

用户N-D10明确：恢复副本是同一本书下的独立新章节草稿。服务端原子建立新章与新工作稿，记录来源、保留原章；相同请求重放只返回同一副本。作者日后自行决定是否正式发布，不把恢复误做原章修订。
