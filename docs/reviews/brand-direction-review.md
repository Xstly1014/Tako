# Tako 视觉方向纠偏 · 2026-10-29

问题：旧首页的奶油绿、纸张装饰及抒情口号，把多元内容社区表现为单一文艺写作产品，偏离用户明确要求。

改变：首页引入原创二次元成年看板娘及同角色 Q 版，采用蓝色品牌与紫色、珊瑚色内容区；改用日常直接文案。短内容、中篇、长文展示创作方向，明确公开发布和发现仍在开发。登录、编辑区同步配色与文案，未修改草稿和登录协议。

克制：无虚构用户、帖子、阅读数、榜单；没有装成已上线的频道和无效按钮。看板娘作为平台形象，不要求用户创作二次元内容。初设可评审，不锁定最终角色设定。

验证：前端 typecheck、12 项同步单元测试、生产镜像构建、8 项 Chromium 浏览器回归全部通过；检查 1280px 桌面与 390px 手机完整截图，人物资源正常、版式未遮挡主要按钮。浏览器自动化中的账号与邮件路由仍用夹具，不替代真实邮箱验收；真实收件登录另由用户确认。

素材来源、路径和完整生成提示词见 docs/brand-mascot-v1.md，使用内置 image_gen，新资源以版本号保存。

待办：用户实际草稿编辑刷新验收；看板娘形象及首页方向反馈；进入下一业务增量前核对开发规格。公开社区、运营审核和发现尚未交付，不能把视觉更新算作内容业务上线。
