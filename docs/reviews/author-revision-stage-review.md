## 已交付主线

作品详情发起修订发行 → 当前会话核对作品、正式V与绑定服务器工作稿R → 明确授权与固定预览 → 追加同一作品正式版本 → 回实际确认作品详情 → 版本／隐藏／历史权限管理 → 公共读取核对。

M2.1冻结work_id单参入口，与C1修订对互斥。先读原journal，无原记录才解析目标；作品/工作稿读取失败不退成通用选稿，不猜R。最新正式标题来自本人版本元数据，工作稿来自该作品服务端绑定，页面不接触C1本机密文／正文。解析结果仅投影稿件ID/R/标题。

M2.2定向准备前再次验证作品/稿件绑定，为本页新预览绑定目标work_id；正式回执的作品不符时不确认成功，保留原请求供核对。恢复的旧journal不强加本次新目标，保持其原身份。发布成功通过实际确认ID进入`/my-works/[id]`，复用M1详情及保护，返回列表不复制路由栈。发行不会自动解除隐藏／限制或改写工作稿。

M2.3复用真实API及现有独立测试库验证发行与展示的组合，没有增加后端表／API或迁移；本机3300通过test环境预检。代码读取API代替直接数据库“修复”结果，测试清理只隐藏本次合成作品并注销自有会话，未改他人资料或清限额。
