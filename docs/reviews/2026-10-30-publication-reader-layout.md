# 发布、读者页面与标签切换稳定性

用户指出两个遗漏页面仍采用旧布局，并反馈作品管理切换分区会抖动。沿用 ui-deai 与 v4 编排规则，本轮不改首页表现力、登录或业务权限。

## 改动

- 发布页统一品牌导航，删除内部 B1 标记。填写信息阶段为独立白色表单，预览阶段为正文与发布确认两栏；步骤、标题、辅助说明、标签和授权有明确间距与分组。成功、过期和结果未确认保留原处理。
- 阅读页将标题、作者、标签和正文放入阅读区域，版本记录独立为次级区域。替换原生折叠箭头，显式按钮打开版本信息/展示记录；已加载正文与重新访问权限保持原逻辑。
- 标签切换稳定性：原实现面板高低差会改变滚动范围，标签加粗也改变文字占宽。根滚动区设置 stable gutter，标签使用固定网格列宽，分区正文使用视口相关的稳定高度与内部滚动。切换后将面板滚动位置归零，不改变窗口滚动，不使用高度过渡。长正文可在面板内继续滚动。

## 验证

- Vue 类型检查与生产构建通过。
- 合成接口的真实 Nuxt 布局检查：390/820/1440 下切换内容、设置、记录，工作区矩形、标签矩形、各按钮矩形和窗口 scrollY 均一致；面板滚动后切换归零。另检查长标题、24 版本、空态与错误。
- 独立 writing_test 真 MySQL/API/Nuxt/浏览器 B1/B2 全链路通过：固定发布预览、丢响应重试、草稿未覆盖、匿名 SSR、不缓存、历史撤权、隐藏期间发布及恢复、受限作者导出和读者过滤。
- 在真服务回归中保存发布表单、预览与读者桌面/手机截图，人工查看表单与读者桌面稿。截图合成账号，未包含真实用户正文。
