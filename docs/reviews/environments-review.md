# 环境隔离与大量内容阶段复盘

## 背景与目标

少量自测作品不足以判断发现入口和管理页能否承载日常使用。本批在 B3.2 之前准备 ECS 正式数据环境与本机独立测试环境，保留云端原内容；不把合成账号、数据库行数当作实际用户或并发成绩。

## 已验证

本机独立库已有 1000 个合成账号、20000 篇中篇。重复导入新增为 0；通过正常密码会话验证发布、版本、隐藏恢复、人工精选、处置与复核，普通作者无法使用运营权限或他人工作稿。三种设备宽度验证发现、分页、筛选、阅读往返，大量作者作品暴露出的列表撑高问题已修正，标签页边界稳定。

后端完整 race / vet、路由与请求响应契约、真实 MySQL 业务检查已通过；增加自定义 Cookie 后的 HTTP race 检查也通过。独立造数保护与备份前缀检查通过。ECS 原 A 数据的升级前离机恢复已通过，9 张表、2 份草稿、9 条历史修订，不公开正文。

## ECS 升级已验证

提交 `492f756` 的 API / web 镜像已校验 SHA256 后传入 ECS。旧进程停写备份后，将原 `tako-ecs-test_mysql_data` 挂到正式项目，逐步迁移至 schema 11；原 8 张业务表摘要一致（排除迁移账本及瞬时心跳），原账号草稿未合并本机内容。正式运营 UUID 从 ECS 实际邮箱查询。新服务环境标记 production，私密接口匿名 401，Swagger 404，未开放公网端口。

每日 OSS 备份服务已在新版本成功执行，timer 仍启用；当前容器总内存约 700MB，未同时运行第二个 MySQL。

原账号本人已设置云端密码，已核对密码记录并切换 password 模式，停止验证码发送进程。用户重登验收发现账号设置页缺少退出入口，现已在共享导航补齐；桌面账号页退出失败可重试、移动社区退出、服务端会话撤销后 401 均通过真实浏览器检查。用户已确认云端密码重登、原草稿与运营入口正常；另指出写作空间退出样式不一致，已合并到统一样式，并增加两个页面计算样式一致性断言。
