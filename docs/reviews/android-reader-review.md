# Android 首条阅读链路 · 2026-11-01

## 背景与本轮范围

用户将独立安装 App 提至 Web 之前，以自己提供的 mobile-app-v1 原型为视觉依据。目前无 Mac/Apple 付费会员，可用 Android 真机，并接受 USB 调试。ECS 已停机，本轮只使用本机 3300 合成测试库，不连接生产。

本轮收口安装路径与“原型开屏/游客入口 → 中篇列表 → 完整中篇 → 返回原列表”。首包自加的最新/精选/标签界面已按用户反馈撤下；接口筛选测试仍保留，不代表 App 提供筛选入口。收藏、两级评论等已有 Web 能力不自动算作 App 完成；原生登录的凭据存储和 API 身份保护仍须单独设计，不伪造 Origin 或关闭同源校验。

## 实现与取舍

- 同仓库新增 `mobile/`，React Native + Expo 58 / Expo Router；独立原生页面而非 WebView。后端规则不拆两份，类型从现有 OpenAPI 生成，本轮没有改业务接口。
- 继承原型蓝白色、三个频道位置、中篇全文字列表与底部导航。当前只有中篇可用，其余明确后续开放；不放模拟数据、赞数、阅读量和假搜索。
- FlatList 保留列表实例与滚动位置，阅读页沿 Stack 返回，直达作品也有回到首页的出口。取消过时请求，分页失败保留列表，后台回来不自动替换已加载正文。
- 15 秒超时、HTTP/契约/环境错误与 404 区分；只有测试环境响应可显示。USB 回环 HTTP 单独白名单，其他域名 HTTPS-only。
- Windows 缺少 Android SDK，隔离 Docker 工具链，不安装或改写主机全局 JDK。模板 debug 签名的 bundled release APK 仅用于个人安装，不声称商店正式包。

## 已有证据

- 类型检查、Expo lint 通过。
- 5 组 Node 测试通过：真实本机 API 的分页、筛选、匿名完整正文与不可用作品，错误环境/异常响应/断网/取消、损坏 JSON 与去重。它们不等于 Android 真机验收。
- Expo Android 资源导出通过：内置 Hermes bundle 与看板娘资源。
- Expo Doctor 20/20 兼容性检查通过。模板自动选择 React DOM 19.3.1 与 React 19.3.0 冲突，已按 SDK 兼容版本固定为 19.3.0，没有使用 force/legacy-peer-deps 跳过校验。
- Google 官方 Windows platform-tools 已安装在忽略目录；当次检查尚无已授权设备。
- 后续用户已连接并授权 vivo V2055A / Android 14 / ARM64，USB `3300 → 3300` 转发通过，默认字体缩放 1.0；尚未据此记作 App 安装或阅读验收。

首次 SDK Manager 下载 NDK 后报 ZIP 读取错误。构建脚本改为固定 Google 官方 r27b 包，校验官方大小与 SHA-1，先测试 ZIP 再安装；该校验与解压已成功。Maven Central 两个官方地址返回 403，已验证阿里云公开镜像可达，通过 Gradle init script 映射相同坐标/版本；不修改生成工程或依赖源码。断点缓存与 SDK/Gradle 缓存不进入 Git。完整编译尚待通过。
