# 中篇复核结果复盘

2026-11-11，主线基线 `ee7fd6a`。现有工作台提供待复核队列和逐条处置详情。运营按既有账号权限，可以把已处理申请的结果、等待时间和原记录入口汇总，用于值班复盘。

```powershell
node --no-warnings --env-file=.runtime/local-test/.env agents/author-support/scripts/review-backlog.ts --outcomes
```

读取全部中篇处置，再分页读取每条处置下的复核历史，按申请统计待处理、维持和撤销。每项包含申请时间、决定时间、处理分钟数、处置范围及原详情路径。正文、标题、申请说明和处置理由均不进入输出。运营可从详情路径回到原记录查看具体原因。

一条处置可有多次申请，因此计数以复核申请为单位。运营撤销处置时会将仍待处理的申请一并标记撤销，记录本身无法证明撤销的原因。此报告按观测结果计数，误判判断需要人工复核原记录。

完整遍历才返回完整计数。请求失败、处置在分页期间变化、时间矛盾或达到读取上限时返回 `incomplete`，计数为 `null`。已完成核对的条目保留为部分观测。边界为 100 页处置、每条 8 页申请，后续使用量超过边界时应按真实规模调整读取方式。

类型及两项定向测试通过，覆盖多次申请计数、敏感字段投影、读取失败和决定时间矛盾。真实本地 test HTTP/MySQL 完整读取 130 条处置及 24 次复核申请，维持 22、撤销 2、待处理 0。该数据来自本机合成测试库，报告不作为治理绩效。运营会话读取完成后退出，审核状态保持由原运营流程处理。

## 周期复盘

```powershell
node --no-warnings --env-file=.runtime/local-test/.env agents/author-support/scripts/review-backlog.ts --outcomes 2026-11-01 2026-11-11
```

日期采用 Asia/Shanghai，包含起始日，结束日不包含。输出本期收到的申请及截至周期结束的处理情况，同时输出本期决定的申请数、结果、超过 48 小时的数量和处理分钟数中位数。以前收到但本期处理的申请进入本期决定数。期后才完成的申请在本期期末计为待处理。若周期尚在进行，截止点使用扫描开始时刻，并在 `observedThrough` 注明。明细同时保留查询时状态及截止点状态。

周期口径由本端按运营复盘需要确定，避免将接收量和处理量混用。完整读取后才计算，未完成读取继续返回未知总数。全历史命令保持原用法。

类型及三项定向测试通过。新增验证覆盖跨期处理、期后决定、截止边界和无效日期。真实本地测试库查询 2026-11-01 至 2026-11-11 不含结束日，完整读取 130 条处置，本期收到 23 次申请，截止前决定 23 次，其中维持 22、撤销 1，超过 48 小时为 0。这些均为合成数据观测。
