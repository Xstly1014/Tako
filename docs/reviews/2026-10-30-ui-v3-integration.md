# 真实前端接入：Q 版登录与版本圆点时间线

## 为什么调整

用户认为既有角色只是插画立牌，版本信息喧宾夺主；明确要求登录表单用 Q 版，并把评审结果接入真实项目。独立 HTML 只用于方向验证，不能算业务交付。

## 本轮实现

- 新增可复用 `LoginMascot`：沿用蓝色挑染、章鱼发夹与蓝白外套；Q 版靠在真实表单上沿。验证码聚焦闭眼，发信状态变化短暂眨眼，失败回到睁眼；验证成功不延迟登录跳转。表情只依赖焦点和服务状态，不读取或追踪输入值。眼部区域叠加切换，身体不跟着生成帧跳动。
- `LoginPanel` 连接原 `/auth/code`、`/auth/verify`，保留 delivery ID、重发间隔、发送状态查询、未确认结果重试、会话与草稿保护。过期会话的 compact 登录保持紧凑，不插入角色。
- `VersionRail` 由作者和读者共用：有限窗口、方向键及 Home/End、触控目标、预览/展示图例。作者读真实版本正文，单独确认才切公开展示；原状态修订检查、幂等标识、丢响应重试保持。读者只接收原接口已过滤的版本，选节点后查看详情，再显式阅读，当前正文不自动替换。
- 版本号、时间及管理事件收进详情。受限版本作者仍可看和导出，不能设为公开；读者完全没有这些节点。不添加尚未实现的 B3 运营节点。
- 新增 `TakoLogo` 和语义颜色变量，用于登录、首页/写作顶栏和读者页；本轮没有重排首页内容或写作编辑器。

## 验证与边界

- 前端类型检查、生产构建通过。
- 原有九个浏览器场景全部通过：真实登录外壳、发送状态及 API 登录、保存重开、断网输入恢复、冲突副本、退出及跨账号隔离、存储降级、手机布局、过期会话紧凑登录。此处认证返回仍为协议夹具，不代表新一轮外部邮件送达。
- 独立 writing_test 真 API / MySQL / Nuxt / 浏览器：B1 固定预览、发布丢响应重试与草稿保护；B2 预览不改公开展示、管理丢响应仅一条事件、历史关闭后重进拒绝、隐藏及隐藏中发布、恢复最新、受限作者导出与正常旧版恢复、读者节点/事件过滤均通过。`scripts/b2_browser_smoke.cjs` 更新交互定位，保留业务断言并增加预览不改变展示断言。
- `scripts/ui_v3_review.cjs` 在真实 Nuxt 页面检查邮箱服务失败、角色聚焦/减弱动效、素材缺失和 390/820/1440 宽度，截图人工检查。发信返回为浏览器夹具，不发送邮件，不把它算作第三方送达验收；既有真实送达结论保持原范围。
- 素材为两张透明 PNG，眼部裁剪叠加；不是完整分层动画，也没有左右转头。素材加载失败不阻塞表单；减少动效与后台标签停止眨眼计时。后续再按用户视觉反馈扩充动作。
- 截图为浏览器视口，不替代 iPhone 键盘、粘贴或真实切网。A 尾项继续搁置。没有修改后端契约或数据库，没有更新 ECS、推送远程或启动 B3。

素材来源：imagegen 基于 `tako-mascot-working-chibi-v2.png` 固定身份生成，原图 `exec-e5f31feb-b484-451f-bd06-adc50db8f036.png`、闭眼 `exec-810ea47d-94f5-4a78-9668-7b3d559b66ed.png` 保留于本机生成目录。

## 用户评审入口

`http://localhost:3000/workspace`（已登录则先退出才能看到登录形象）与 `http://localhost:3000/my-works`。使用非私密测试作品查看节点、版本详情和公开展示操作。视觉仍待用户确认，不以测试通过宣称设计定稿。
