# App 作者作品管理阶段复盘 · 2026-11-02

## 问题与交付行为

App 已能阅读、收藏和评论，但作者从“我的 → 作品”只能看到未开放提示，无法管理已发布内容。用户明确分工：同事继续 C1 加密草稿/同步/创作页，本端接入作者作品管理。实现沿用 B2 的既有业务权利与 OpenAPI，未新增后端接口或 schema。

本阶段新增本人正式作品列表、作者版本正文与管理记录，接入隐藏、默认恢复最新版、受限最新版时显式选择正常旧版恢复、切展示版本、开放/关闭历史正文。每次动作先确认，使用冻结的 mutation_id 和状态修订；丢响应保留原请求，成功后重新读取现状。并发冲突要求重新读取并再次确认，不以历史回执冒充当前状态。平台限制不能通过恢复、切版或历史开关解除，管理动作不覆盖工作稿。

退出/失效/切号由现有会话代次使私密视图重建，旧请求不能填入新账号。未确认操作只留当前页面内存，离开时提示，重入不自动补发。未引入正文持久化、导出分享、草稿读写或新账号权利。
