## 组件、状态与样式

外壳为 `_layout.tsx` 的 SafeAreaProvider→SessionProvider→Expo Stack；各页面自行放置安全区、顶栏与底栏。`theme.ts` 提供颜色，尚无统一间距/字号/操作层级 token。`PrototypeUi.tsx` 管底部导航/创作面板/占位动作；`Ui.tsx` 的 Action 是统一主色大按钮，既用于主要动作也用于返回/筛选/刷新。阅读列表使用 WorkRow，评论由 CommentsPanel 承接。

重做应保留会话、API、授权、DraftEditor/PublicationFlow、操作记录和数据存储语义。页面内部目前混有业务状态与 JSX，不能整文件替换以免丢失失败/恢复分支；实现时先明确纯视图替换范围。共享 token、导航、C1/小说页面是并行触点，需写清布局写入与主开发在途业务的边界后修改。
