# 页面编排规则 v4

依据用户五张批注截图与 ui-deai，先确立规则，再修改真实页面。

## 问题归因

作品页把作品设置、版本选择、正文和操作记录串成一长列，没有分组容器；同一标题出现两次，按钮散落，空隙来自多套全局 margin 叠加。两三个节点却被拉满整行，原生 details 标记又与装饰箭头混用。首页装饰符号和多色卡片比内容更抢眼。上轮只验证功能与溢出，没有按真实任务检查视觉层级，验收不足。

## 必须执行

1. 导航固定为品牌、工作区入口、账号区三个组。链接表达去向，不追加 Unicode 箭头。翻页使用带无障碍名称的标准线条图标，只在确实可翻页时出现。
2. 作品管理按“选作品 → 看版本与正文 → 处理设置”组织。左侧作品列表，右侧白色主工作区；作品标题只作一次主标题。主操作为准备新修订，阅读为次操作。可见性与历史权限归入独立设置面板。
3. 正文有独立阅读区域，版本选择贴近正文。版本号和精确时间进入选中后的信息面板；详情与管理记录用同组切换，不做两个相距很远的原生折叠行。
4. 间距只用 4/8/12/16/24/32/48；同一信息组内部 8–12，组间 24，页面区块间 32。标题、状态、工具栏各自有明确行高，正文不套工具栏布局。
5. 标题 24/28，区块标题 16/20，正文 14/16，辅助 12；400/600 两档。明确系统无衬线字体栈，禁止工具页继承展示页字体或字距。
6. 品牌蓝只用于主操作、选中、链接。白底工作区搭配中性灰页面底；无阴影，边界只有一层细边框。首页三种内容用同一中性布局，删除箭头、星号、编号和重复标签等装饰。
7. 每个操作栏用 flex/grid 显式分组、允许窄屏换行；不靠空格、换行或不同 margin 拼布局。少量时间线节点按固定步长排列，不随容器拉开。
8. 版本详情切换与设置开合只是 UI；服务端权限、幂等确认、未确认重试、正文快照保护保持。加载、空列表、错误、受限、长标题和手机窄屏必须可用。

## 用户继续评审后的校正

首页不是工具页。用户明确要求保留原有张力：大标题、蓝色强调、角色动势与较大的画面占比，不把“去掉装饰箭头”扩大成“降低全站表现力”。首页角色改为伸手近景，登录继续 Q 版；首页展示字体允许适度合成字重，防止无粗体回退字体被 `font-synthesis:none` 强制渲染成普通字重。工具页仍以清晰任务分组为优先。

## 验收

逐页检查首页、登录、写作空态与编辑态、作品管理（正常/历史/隐藏/受限）、读者与发布页。保存真实页面合成账号截图，人工检查层次与段距；390/820/1440 检查无溢出和操作可达。继续运行真实 B2 回归与既有写作回归。自动化通过仅说明功能约束通过，视觉仍待用户评审。

## 发布、阅读与标签稳定性补充

- 发布页：顶栏使用同一品牌导航；信息填写为单栏白色表单，预览阶段再拆正文与确认侧栏。发布结果、加载和错误保持明确分组，不展示内部 B1 标记。
- 读者页：白色正文阅读区，标题/作者/标签集中，版本记录为独立次级区；技术权限说明不占主视觉。保留已加载正文的阅读保护与重新访问时的服务端权限检查。
- 分区切换：根滚动区预留滚动条，标签分配固定列宽，面板使用稳定的视口相关高度和内部滚动。切换只重置面板滚动位置，不滚动窗口，不用高度动画。验收比较窗口滚动、标签与卡片的矩形坐标，不能只检查横向溢出。
