# App 作者作品管理 · M1

2026-11-02。用户明确分工：本端实现作者作品管理，同事继续 C1 草稿加密仓储、同步和创作页。本分支 `codex/mobile-author-works` 只新增作者作品客户端、状态逻辑、页面及测试，个人中心仅替换既有“作品”占位入口；不改草稿箱、会话、依赖、后端或契约。

作者从“我的 → 作品”查看本人正式作品，稳定分页，选择作品查看作者专属版本和管理记录。沿用 B2 权利：隐藏、恢复、展示切换、开放/关闭历史正文；作者可查看本人受限正式版本，但受限版本不可设为公开展示，作品整体限制优先。默认恢复最新正式版本；最新受限必须明确选择正常旧版，禁止静默回退。操作确认展示版本及当前历史开关；任何管理动作不覆盖工作稿，不自动发布稿件或解除平台限制。

复用 OpenAPI `/api/my/works`、本人作品状态/版本/动作接口，无新增 API。动作使用 mutation_id 和 expected_state_revision；未知结果只重试原请求，不接受新动作。成功回执之后重新读取当前状态，回执不冒充现状；并发冲突重新读取，用户再次确认才创建新操作。版本与事件独立分页，状态变化时重新读取，失败保留已加载列表，异常分页不当成空数据。

管理动作已确认后，现状读取失败必须继续明确显示操作已确认，单独提示读取失败；重新加载只读取现状，不重发管理动作，不将历史成功回执作为当前公开/隐藏状态。读取成功后移除读取错误并展示服务器现状。

全部私密视图由现有会话授权；切号、退出或失效立即隐藏，迟到响应不得回写。管理动作只在页面内存保留，离开有未确认操作时明确提示；关闭 App 不自动补发，重入只读服务端现状。此处不保存标题、正文或操作到本机文件，不改变 C1 草稿或评论的存储策略。

交付包括客户端、可达页面、错误语义、模型/真实 API/组件失败验证。工程检查和远程 CI不等于 Android 构建或真机验收。P0：面向真实移动作者交付前补设备返回、长正文和生命周期；P1：本阶段须验证账号隔离、幂等/丢响应、并发冲突、受限恢复及读取失败，不能只交规格或基础类。
