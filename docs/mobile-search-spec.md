# S · App 站内作品搜索

2026-11-02。业务范围由用户确认：先搜索标题、作者笔名、简介；不包含正文。本阶段主开发负责规格、后端及必要契约生成；另一端继续 CI/M1/C2、独立复验及设备工作。用户告知同事已有 USB 条件，但其远程进度尚未发布本轮设备认领/结果，不能称已验收。

## 解决的问题与范围

读者已有作品名、作者或主题线索时，应能主动找到可读中篇，进入阅读并返回原结果。当前只能浏览精选、最新、标签；原型搜索入口尚不可用。本轮为已存在的公开中篇增加新发现路径，不新增短内容/长文实体，不增加算法推荐或外部搜素服务。

用户已确认的搜索对象仅为当前公开中篇的标题、作者笔名、简介。笔名匹配返回其作品，不是账号目录；未发布作品的账号不单独成为结果。私稿、固定预览、待审未正式提交、历史正文/标题和评论均不参与。

## 首版规则

- 去除首尾空白，1～64 Unicode 字符；不允许控制字符。保留中间空格作为连续短语，不分词、不纠错。英文大小写不敏感；中文按原文连续包含匹配，不支持拼音/简繁转换。
- 三个字段任一包含关键词即命中；百分号、下划线、反斜线和转义字符按普通文字检索，不能变成 SQL 通配语法。参数化查询，不拼接用户 SQL。
- 返回来自当前展示的正式版本，复用发现页公开资格：作者未隐藏、作品未受限、当前展示版本未受限。每页请求重新判权；点进阅读仍由阅读接口重新判权。待后审正式版沿原规则可读。
- 按首次正式发布时间、作品 ID 倒序，每页12条；修订不顶帖。没有个性化或热度评分，不输出虚构命中数。空结果是200空列表，不是404。
- 游标绑定规范化关键词的散列，不把关键词明文放入游标；换词必须重新搜索，坏游标/跨查询复用为400。分页为实时结果，不承诺跨请求固定快照；内容、笔名和公开资格变化可能使结果退出或进入，客户端按作品ID去重。
- 不建立搜索历史、热门搜索、联想词或远程搜索词日志。本轮 App 输入仅当前页面内存；不增加用户画像或持久偏好。

## S1 · 服务端可交付段

`GET /api/search?q=...&cursor=...`，匿名可用；200 `{items: DiscoveryCard[], next_cursor: string}`，最多12条。不回正文、邮箱、私稿ID、查询词或总数。400 invalid_input（缺词/空白/超长/控制符/重复或未知参数/坏游标），503 publication_disabled 或 service_unavailable，500 internal_error；请求ID与no-store沿统一中间件。

先复用 MySQL 的当前正式版联表、参数化字面包含查询和已有卡片读取，不新建搜索集群或派生索引。查询有2秒服务端预算并继承取消；不声称现有索引能优化前置通配。S1需路由覆盖、OpenAPI请求/响应、真实MySQL的权限/版本/分页/中文和特殊字符验证。使用独立测试库，不重启同事手机所连的3300 API。

P1：在S2交付前，用已有2万合成作品完成常见/无命中/单字符/深分页的查询计划与耗时记录；这不等于并发容量或高可用证明。如果普通请求接近2秒预算或干扰现有读取，先调整索引/检索实现，不以加超时或加机器掩盖。大规模全文与中文分词另议。

## S2 · App 接入（不提前算交付）

保留原型搜索入口，独立搜索页；明确提交后搜索，不逐键发送；加载/空态/失败可重试。换词取消旧请求，迟到响应不能覆盖新词结果，分页沿当前查询，失败保留已加载结果。阅读返回保留输入和列表位置；不强制登录，不假装搜索尚未实现的短帖/长文。不修改当前创作/发布页面或用户原型文件。

App页面与键盘/返回细节遵循ui-deai和SDK58文档，接入时补模型、真实API、实际组件及包一致性；设备验收绑定具体APK。S1只有API不能宣称读者已经可以在App搜索。

### S2 实际接线边界

已读现有 CommunityScreen 与原型 index.html：搜索框右侧九点是“仅关注”，与搜索无语义关联；本轮不把它改造成搜索过滤器，关注保持未开放。社区点击搜索进入独立 /search，返回社区；在结果进入 /works/[id] 后系统返回保留搜索页实例/关键词/已加载列表与位置。输入框、清除、明确“搜索”、返回使用现有品牌色、Icon和间距，不增加营销标题、渐变卡片、箭头字符或假热门词。结果延续中篇无封面文字列表，不改变其他频道。

主开发下一段认领 mobile/src/api/search.ts、mobile/src/search/**、mobile/src/app/search.tsx、CommunityScreen搜索入口及自身测试；不改C2/M1/会话/CI门禁，新增测试分类交既有门禁所有者按接口接入，或与其明确最小共享触点。生成声明仍由主开发从OpenAPI生成。设备验收用独立冻结基线，不在同事打包中途变更运行源。

搜索页区分“输入中的词”和“已提交的词”；键盘搜索/按钮仅提交一次，换词明确取消旧请求、递增代次，所有迟到success/error/finally都核对代次，防止旧请求清除新加载状态。初始输入、空结果、失败重试、加载中禁重入、分页失败保留已加载列表分别验收。输入改动不等于已重新检索；未提交的词不能被用来翻旧结果的下一页。清除输入终止当前查询并回初始态，原请求不应在之后重新填结果。

## 验收与退出

同名多作品/一个作者多作品，标题与简介分别命中；全文独有词不命中；隐藏/受限后不命中，旧版独有词不命中，切展示版与笔名变更后按新可见字段；12+作品分页无静态重复、同发布时间按ID稳定、换词旧游标被拒；`% _ ! \`字面匹配；空词、坏游标、断库/取消、发布开关关闭均有错误语义与契约验证。不会重置现有库、发信或操作ECS/设备。

S1工程结果已交付源码/契约与真实MySQL验证，当前规模查询基线已完成，详情见 [复盘](reviews/public-search-api-review.md)。S2与稳定测试服务升级尚未执行；不因HTTP接口存在把原型搜索入口标成可用。
