# 社区发现与反馈 · 规格及实现边界

发现、人工精选与共享导航已接入本机，工程与用户本人功能验收通过；收藏与单层评论尚未实现。见 [本批设计](community-discovery-design.md) 与 [复盘](reviews/community-discovery-review.md)。

## 已确认

- 当前大视觉页面为官网。官网提供醒目的社区入口；社区首页承担真实内容浏览，与创作/运营工作区区分。
- 优先闭环为官网进入社区、浏览、阅读、收藏与单层评论。B3.2 暂缓，既有人工治理保留。不做评论回复树，不以占位按钮冒充已有能力。
- 首版只收录当前公开、未受作品或版本限制的正式作品。从真实中篇开始，不展示虚构作品、阅读量、榜单或不可用短内容/长篇入口。
- 人工精选、最新发布、已有真实风格标签浏览。个人化推荐和算法不作为首版前置条件。
- 私测身份采用用户自主邮箱+密码注册，取消邀请机制，不要求邮件验证；游客可读，注册后可写。邮件登录暂收起，既有账号和数据保留，见 [自主注册边界](private-test-registration.md)。
- 桌面参考起点/B站的信息组织，手机参考小红书的信息流；参考布局仍需评审，不能推定封面、广告、搜索或榜单已经在范围内。

## 与已有业务保持一致

- 作品卡片的标题、简介、标签来自当前展示的正式版本，而非工作稿、未提交预览或私密历史版本。简介仍由作者提供，不擅自截取正文补齐。
- 列表与阅读复用公开资格条件：作者未隐藏、作品未受限、当前展示版本未受限。正常作者的待后审正式作品不因“待后审”被额外封禁。
- 精选位置不能绕过公开资格；隐藏或限制后，新请求中不显示卡片及其元数据。点击作品后服务端仍重新判权，不能因为在列表出现过就绕过限制。
- 人工精选选择作品，读者仍进入稳定作品链接；切换展示版本后，卡片与正文跟随同一正式版本。作品隐藏、作品受限或当前展示版本受限时撤出精选；恢复后需运营重新选入，不能仅靠查询过滤实现暂时消失、恢复后自动回榜。
- 最新发布按首次正式发布时间排序；修订、切换展示版本或隐藏恢复均不顶帖。同时间使用稳定唯一标识作为排序补充，分页不因修订产生重复。
- 收藏绑定作品，重复收藏不产生多条记录；取消收藏可重试。“我的收藏”保留隐藏或受限作品的关系记录，但不返回其标题、简介、正文等受保护元数据。
- 评论沿用已有共识：合并展示，标记发表评论时实际阅读的正式版本，不因新版本发布将旧评论改绑到新版。不按版本拆成多个评论区。版本归属必须在服务端验证，不能信任任意客户端版本号。
- 评论来源的旧版本受限后，评论继续公开，只关闭该版本的阅读入口，不连带隐藏评论。关闭历史阅读权限同样不隐藏评论。版本标记不返回受限版本的标题、正文或其他受保护内容；读者不能由评论入口绕过原有版本权限。
- 评论独立接受内容处置：即使来源版本正常，违规评论也可由运营屏蔽；即使来源版本受限，正常评论也不自动受限。若整部作品已隐藏或受限，作品评论接口仍遵守作品访问权限，不单独开放隐藏作品的评论页面。
- 沿用已有共识中的权利区分：评论者可删除自己的评论，作者可删除自己作品下的评论，运营可因违规屏蔽；普通用户不能删除或修改他人评论。用户界面及业务契约统一使用“删除”，不提供“撤回评论”状态或操作。重复删除不重新显示评论，也不产生额外删除结果。
- 首版评论发布后不提供编辑，修改需删除后重新发表；不做回复、点赞与通知。独立读后感属于独立内容，不等同于作品评论，本轮不实现。
- 对外展示的标签和数量必须来自真实可读内容。标签无作品时提供清楚空态，不用假内容撑满布局。
- 同类工作区统一导航、公共锚点与可往返入口，随本次发现入口一起交付；阅读区允许更窄，但不应连同公共导航一起跳位。

## 正在讨论

1. 评论长度、提交频率等输入边界及服务端版本归属验证方式。
2. 精选数量、排序及运营入口；初期无封面作品如何形成可读的推荐位。
3. 具体桌面/手机信息组织、官网与社区路径、搜索首期边界。
4. 收藏与单层评论的分页、重复提交、跨账号权限及失败重试验收。

## 实现前验收场景

隐藏/受限元数据不泄露、卡片与正文版本一致、深链接进入及返回路径合理、分页无重复、没有精选/没有标签作品/列表请求失败可理解、移动端导航仍可达。功能测试不代表推荐有效；后续需实际用户验证能否发现作品并愿意留下反馈。

评论专项验收：阅读 V1 后发布 V2，评论仍标记 V1；限制 V1 后该评论继续展示但不能打开 V1；关闭历史阅读不隐藏评论；单独屏蔽评论后读者不再收到评论正文；评论者和作品作者可删除，第三方不能删除；删除后重试、刷新及并发请求不会恢复评论。版本或作品恢复不应恢复已经删除的评论，也不能清除独立生效的评论处置。

外部验证以真实路径证据记账：非开发者能进入、独立找到并发布/阅读作品，明确完成收藏或反馈。阅读完成不能只凭打开页面推断；回访等指标需定义观察窗口。自主注册使多邮箱发信不再是本轮私测前置条件；可访问入口和非开发者实际完成任务仍需验证，不以本机界面完成代替。
