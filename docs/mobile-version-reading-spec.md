# App 历史版本阅读 · 2026-11-02

## 目标与范围

补齐原型与既定 B2 权利：读者在 App 看到正常正式版本的点线时间线，点击节点查看次级版本信息，作者授权后可切换历史正文。复用公开时间线与指定版本接口，不改后端、账号权限或数据库。此链路完成后再进入 App 创作规格，不同时新增推荐、关注或通知。

## 页面行为

- 时间线放正文之后，使用点与线；不把版本号、发布时间铺满正文主视野。选中节点后在下方显示日期、版本号及“正在阅读／默认展示／历史版本”等次级信息。
- 点击节点只看详情，明确点击“阅读此版本”才换正文。作者关闭历史时仍可看正常节点日期/版本号，不能读未授权历史正文；以服务端每次读取的权限结果为准。
- 只展示公开 API 返回的正常正式节点，不补齐缺号，不猜测或展示被限制节点。版本独立分页，每页最多 20；不新增管理事件列表。
- 正文切换成功才一起替换标题、正文、标签、发布时间和评论上下文，回到该正文顶部。失败保留已经加载的内容与阅读位置，提示并允许重试；不自动退回默认版本冒充成功。
- 已加载内容遵守原“允许读完”规则；时间线失败、历史关闭或新版本出现不抹掉本次正文。切换/重开属于新访问，重新校验。
- 连续点击、分页与刷新请求使用取消和代次保护，旧响应不能覆盖后选版本或重新加载后的列表；列表去重，分页失败不吞掉旧节点。

## 与评论、收藏及返回的关系

同一作品内切正文不新建评论编辑器，内存文字与回复目标保留；成功后新发表使用新正文的上下文。已有不确定发表请求保持原 mutation_id 和原上下文重试，不在换版本时自动重发。评论仍绑定作品、不记录版本。评论面板打开时不能同时操作底层时间线。

收藏仍绑定作品，不因历史版本变更创建新收藏。离开阅读页仍沿用已有未发表文字保护；关闭 App 不恢复评论文字。返回入口仍回原列表，不为切版本堆积路由。

## 验收

1. 客户端接口：字段守卫、无效 ID/版本拒绝、返回身份匹配、历史关闭/限制的 404、断网与畸形响应。
2. 真实 3300：验证多版本时间线、关闭历史只可看元数据、开启后读取、关闭/限制后拒绝新读取，以及现有评论权利兼容。需要新建测试内容时仅创建合成内容，不修改既有用户作品。
3. 组件组合：点节点不自动换正文、授权与不可读文案、分页失败重试、切换失败保留原正文、迟到响应不覆盖新选择。夹具不是手机证据。
4. 类型/lint、Android 可构建；手机条件恢复后补横向节点触控、滚动回顶部、安全区、评论收起后切换、硬件返回与生命周期。未完成不宣称真机体验通过。
