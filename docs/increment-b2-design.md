# B2 技术设计 · 版本管理与可见性

2026-10-30。继续已确认业务，不重开视觉设计。受限正文作者仍可查看和导出，但不得把受限版本设为公开展示，用户已确认。

- 新增 works.state_revision；发布或管理状态改变递增。作者动作提交 expected_state_revision，过时返回 work_state_conflict。成功重试先返回原确认，不重复追加事件；界面重新获取当前状态，不把旧确认套回最新设置。
- 复用 B1 账号锁顺序，所有管理动作 owner→work；原子更新状态、写不可变展示/可见性事件与幂等确认。工作稿不参与改写。
- 恢复默认最新版；最新版受限时返回 version_unavailable，允许作者明确选择正常旧版。作品整体受限时禁止恢复，不自动解除平台限制。隐藏期间仍可发布，新版推进正式编号但不解除隐藏或平台限制。
- 作者接口单独授权，版本列表与正文只属于本人；读者接口只返回正常版本号/时间/可读性和可公开的展示切换记录，不返回旧标题或正文。受限版本及涉及受限目标的事件不出现在读者时间线。
- 作者隐藏、权限开关等私有管理事件仅作者可见。公开状态下的展示切换和恢复可进入读者时间线；隐藏期间的私有切换不因之后恢复而追溯公开。正文仍经 B1 统一读取判断。
- 版本与事件分别稳定分页，每页 20；作者作品列表按创建时间/ID 稳定分页。单次时间线读取用同一只读一致性事务，避免读到互相矛盾的权限快照。
- 新增作者作品入口、版本预览/导出、历史开关、隐藏/恢复/切换确认。当前加载的读者正文不被自动替换；点击另一个版本是明确导航，关闭权限后的新获取被拒绝。
