# 短内容首包 · 图文发布与本人长文关联

2026-11-10 已确认首包包含文字、配图和本人长文关联。三个频道分别展示。每帖可选零至四张 JPEG/PNG，图片与同次正文一起审核。关联长文不可读时，短帖保留公开，卡片消失且不泄露书名；长文恢复可读后，卡片随当前资料恢复。本页是开发规格。

## 作者与读者如何使用

- 登录作者从短内容频道发帖，填写标题和正文，选择图片并调整顺序，可关联一部自己的公开可读长文。首版可用的初始长度上限为标题 80 字、正文 2,000 字。详情底部显示关联卡片，点击进入长文目录；从目录返回能回到原帖。
- 游客可以浏览独立短内容频道与详情。频道使用首次公开时间倒序分页，修订或隐藏后恢复不顶帖。有图以第一张作为频道封面，无图展示标题及正文摘录。沿用手机端原型的图文布局，列表只请求有界的卡片数据。首包暂不提供热榜、算法推荐、点赞与讨论。
- 作者确认发布前核对固定快照，包含标题、正文、图片顺序和关联目标。确认时由服务端重校验关联归属与当前可读。若选中的作品在确认前变为不可读，保留表单并提示移除或重新选择。发布成功以后，关联卡片只从当前公开长文查询生成，不将书名、简介或章节状态复制到帖子公开快照。
- 作者可隐藏与恢复短帖，恢复采用最新可展示正式版本，并保持原首发时间。平台限制优先；未解除限制的版本不可通过作者恢复公开。沿用已确认的短内容修订时间线，作者控制历史正文开关，默认关闭，受限版本对读者不可见。关闭或限制一个版本时，该版本的图片入口也随之关闭。
- 正常账号先发后审，观察期先审后发。运营只能看作者明确提交的固定快照。修订待审期间，读者继续读原正式版本；首次待审没有公共正文、图片或卡片。被替换的待审稿不增加公开版本号；驳回原因与记录仅授权方可见，工作稿留在作者手中。已有待审提交仍由人工处理，观察期到期或撤销不自动放行。使用现有处置与站内复核规则，短内容不会因关联存在而获得额外的发布权利。

## 图片授权与失败处理

- 选择图片只建立私密素材，公共图片入口同时校验帖子、版本、图片引用和当前可见性。已知图片 ID 或旧 URL 不构成访问授权。公开页面的缓存不得继续分发隐藏、受限或关闭历史权限的图片。已下载内容无法远程收回。
- 上传验证真实文件格式和像素尺寸，再解码重编码去除 EXIF 等原文件元数据。服务端限制请求体、解码像素、账号暂存量和并发。初始工程上限为单图输入 8 MiB、12 MP，拒绝损坏文件并提供具体提示。应用内能取消选择、移除图片或重试失败项。公开 API 不返回私有存储路径和临时上传链接。
- 发布请求绑定作者、固定预览及原请求标识。任一图片未上传确认、越权、与固定版本不匹配时，不产生可读半成品。网络丢响应时查询或重试原请求；换账号不展示上一账号私稿、私图或原请求。用户不必为一张图片上传失败重新输入正文。
- 媒体服务和备份使用私有存储。第一条真实服务验证使用本机隔离环境。上线前验证进程重启、库与媒体的一致恢复和容量。定时回收只处理经重新核验无任何草稿、预览、提交或版本引用的临时图片，并用并发测试防止提交与回收相撞。关联目标隐藏或版本切换只影响可见性。

## 实现批次与退出条件

| 批次 | 验收出口 |
|---|---|
| 服务 | 同一发布事务固定文字、图片和关联。以 OpenAPI 记录上传、发布、读图和拒绝语义。用真实 MySQL 验证四图边界、越权引用、幂等、旧链接和长文隐藏/恢复。沿用现有同源和作者认证。 |
| App 与运营 | 作者选图、检查上传状态、预览、提交，游客从短内容频道到详情和长文。运营能核对同版本图文，处置后新读不能取回图片。真实 HTTP/MySQL 联调覆盖断链重试、部分上传失败和跨账号隔离。 |
| 真机与运行 | 先退出既有 C1 P0 门槛，再用对应 APK 验证原生相册授权、选择/取消、后台/弱网、返回现场与切号。扩大到外部用户前补媒体恢复及运行容量证据。 |

主开发认领短内容后端、OpenAPI、App、必要运营页面和联调；并行端继续负责作者 Agent 评测。分批提交可验证的完整路径，待首包图文、作品关联和治理一起通过验收后再开放短内容入口。
