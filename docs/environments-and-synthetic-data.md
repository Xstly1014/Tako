# 正式与测试环境分离

本批优先于 B3.2。用户已选择 ECS 正式环境、本机测试环境，ECS 原有账号草稿增量升级，不合并本机数据；正式运营沿用已确认邮箱在 ECS 中的实际账号 ID。本机原有数据与备份独立保留。

## 两套日常入口

| 环境 | 数据用途 | 访问方式 |
|---|---|---|
| ECS 正式环境 | 保留真实账号与正文，禁止导入合成数据 | 先沿用 localhost:3100 的 SSH 私有转发；不自动开放公网 |
| 本机测试环境 | 大量合成用户和作品、状态与布局验证 | 独立 Compose 项目、MySQL 卷、数据库用户与网络，入口使用 127.0.0.1 的独立端口 |

旧 localhost:3000 开发数据不因本次任务被删改或自动迁入云端。测试入口、正式入口采用不同会话 Cookie 名与页面环境标记；浏览器草稿存储按 origin 隔离。依赖缓存与应用构建可以复用，账号、正文、凭据、会话和备份不能混用。

## 正式升级边界

1. 读取实际运行版本、资源与数据卷，不以历史文档替代现状。
2. 使用 ECS 对应的加密密钥完成升级前备份、离机下载与本机独立恢复；不在 2GB ECS 上同时启动另一套 MySQL 演练。
3. 同一份已验证应用构建用于两套环境，凭据运行时注入，不放入镜像。ECS 保留数据库卷及原有密钥，增量迁移，不降级或重建库。
4. 保留私有监听与关闭 Swagger，单实例更新存在短暂不可用窗口，逐项检查 web、API、授权、后台任务与备份。
5. 旧账号先通过已有合法会话/验证码设置自己的密码，再切密码模式；不按相同邮箱复制本机密码或接管账号。
6. 新增业务数据还须完成升级后的离机恢复核验，正式环境不接收造数工具输出。

## 测试数据设计

本机已导入 1000 个合成账号、20000 篇作品，数量参数可调。只有当前已实现的中篇实体，不以造数冒充短内容或长篇功能。

- 题材覆盖六种现有风格，包含单/多标签、不同标题长度、简介空值/上限、中文/表情、短篇幅和长正文。
- 覆盖正常公开、隐藏、作品/版本受限、历史开关、多版本、不同展示版、待后审及已处理等已实现状态。
- 准备正常用户与运营的可登录测试账号，采用正常密码登录；其他展示账号明确为合成身份，不寄送邮件或伪装为真实活跃用户。
- 作品、快照、正式版本、预览、后审及审计关联保持一致，保证不仅能浏览，也可继续修订、隐藏、治理及测试并发。
- 初始公开时间分散，测试翻页和筛选，不用同一时间/同一标题重复灌满所有卡片。
- 保留空、少量与大量内容三种验收场景，重点验证真实布局与可用性，不把 20000 条数据当成并发/留存/推荐效果证据。

## 防止误写正式库

造数工具只在显式 test 配置、专用测试数据库名及数据库内测试标记一致时运行，生产库缺少标记直接拒绝。构造工具独立于线上接口，不提供跳过认证的业务入口，不内置正式账号或生产凭据。重复执行必须有明确记录和幂等/续跑行为，不用无条件清库解决重复数据。

## 本批退出条件

两套入口可识别且数据互不影响；云端原有内容保留；测试填充可重复；多内容情况下桌面/手机界面、筛选、分页、长标题、版本和权限经过真实服务验收。正式账号迁移与新增数据离机恢复单独记录，不由本机测试代替。

## 本机已验证行为

- 入口为 `http://127.0.0.1:3300/community`；原开发入口 `localhost:3000` 的数据保留。
- `python scripts/local_test.py init/migrate/seed/up/status` 分别管理专用配置、增量迁移、续跑造数和启动检查。再次执行 `seed --users 1000 --works 20000` 新增为 0，原有手工修订未被覆盖。
- 三个可登录测试身份为 `operator@tako-test.invalid`、`author@tako-test.invalid`、`reader@tako-test.invalid`，密码分别在本机 `.runtime/local-test/.env` 的 `TEST_OPERATOR_PASSWORD`、`TEST_AUTHOR_PASSWORD`、`TEST_READER_PASSWORD`。配置不可提交或复制到正式环境。
- 普通密码登录后，真实 API 已通过修订发布、历史权限、限制、文字复核与撤销、隐藏恢复不自动入选、人工重新选入及跨账号拒绝验收。
- 浏览器在 1440 / 820 / 390 宽度验证精选、分页 24 条不重复、风格筛选、阅读往返与无横向溢出；作者大量作品列表独立滚动，内容/设置/记录切换边界不位移。截图在 `docs/design/community-large-*.png` 和 `test-manager-large-*.png`。
- 会话 Cookie 与运行时 OpenAPI 同步部署名，API 响应带 `X-Tako-Environment`；测试页有固定环境标记，不提供线上绕过认证接口。

## ECS 升级操作

使用 `scripts/ecs_release.py --host ... --identity ...` 打包已提交的应用镜像和白名单部署文件，不上传本机 `.env` 或测试数据；校验传输哈希和镜像 ID 后运行 `ecs_promote.py`。升级先停写并加密备份，停止旧 MySQL 后才挂载既有卷，比较迁移前后原表逐字段摘要；失败保留迁移与卷，恢复旧应用配置。正式备份新对象放在 `tako-backups/production/`，原前缀规则继续覆盖。

正式环境第一次升级暂保留邮箱登录供原账号本人设置密码，确认后才切密码模式。正式环境完成状态以阶段复盘的实际记录为准。
