## 分工与继续工作

主开发负责全部非Agent业务、契约、App/Web、CI、集成、APK和设备；并行端仅负责agents/author-support及业务评测/费用/其自身进度。分别维护[主开发进度](handoff/primary-progress.md)与[并行端进度](handoff/parallel-progress.md)，发布不等于对方已读。每次推送前fetch、检查新增提交/认领/重叠，普通合并，禁止force覆盖。

当前状态只在本页汇总；操作入口链接到本页，不再往入口顶部追加重复版本快照。阶段证据写reviews，连续认领写各自progress；不能用状态页覆盖用户已确认权利或历史证据。
