# 小说发布与生命周期真实服务回归

从仓库根目录运行 `node scripts/check_novel_publication_live.cjs`。先按重启手册启动本机3300测试环境；API、MySQL和Web必须来自同一份源码，运营测试账号需已配置。CI使用隔离合成环境和相同入口，不使用ECS或真实邮件。

脚本贯通实际App管理页面、实际运营Web与同一HTTP/MySQL，覆盖发布、观察期、完结、指定整改及固定正文隔离。浏览器运营使用真实Cookie和Origin；Docker内只重写目标地址，不关闭同源保护。四个生命周期提交在服务受理后丢响应，重开只查询原结果；确认后GET失败不得恢复过时权限。

App部分使用明确的DOM、导航和journal适配器；这些证据不能替代Android原生加密、安装和真机验收。真实设备任务见 `docs/handoff/device-requests.md`。截图仅合成测试内容，保存在忽略的 `.runtime/novel-lifecycle/`，不作为公开产品截图。
