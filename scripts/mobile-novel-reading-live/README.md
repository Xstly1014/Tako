# 真实续读链路验收

仓库根目录执行 `node scripts/check_novel_reading_live.cjs`，仅接受本机3300 test环境，要求API0.27/迁移25及已有工具镜像/依赖。自动创建example.test合成作者/读者与小说，不发真实邮件，不打印正文/密码/令牌。

实际Session/API/阅读页面对真实HTTP/MySQL；导航、FlatList视口、journal为显式DOM/内存适配器。因此能验证真实授权、CAS、原回执、版本变化、账号和页面行为，不能证明Android原生加密、真实滚动/生命周期。AES/SQLite模型与设备验收另计。

同一批次还覆盖实际“我的→我的书架→目录→正文→返回”、加入/追更开关/移出、两次书架受理后丢响应只GET恢复、列表与目录确认后GET503、不可读时仅关/移出，以及退出换号/同号重登恢复。八次明确书架操作各一次POST，移出不删除私人位置；正常成功自动刷新，恢复确认仅在未知/本机失败时出现。UI明确站内新章提醒尚未开放。

覆盖发布后阅读、服务受理丢响应、只读原结果、两种冲突选择、源版本改变、纯读者断网身份但草稿仍锁、跨号不继承位置、隐藏后当前阅读保留且新请求拒绝。finally只隐藏本次合成作品和注销本次会话，保留审计；失败的历史合成数据不全局清理。截图在忽略目录.runtime/reading-live，仅合成内容。预检失败不绕过或冒充跳过通过。
